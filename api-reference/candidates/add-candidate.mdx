## Overview

Manually add a candidate to a job — for example, when a recruiter sources a candidate directly. The new candidate is created with an initial `candidateStatus` of `APPLIED` and a `source` of `MANUAL`, and a `CANDIDATE_ADDED` audit event is emitted. For bulk resume ingestion use the bulk resume-upload endpoint instead, and poll `getBulkUploadJob` for its progress; use `updateCandidate` to edit the row after creation.

<Note>
This operation requires the **write** scope.
</Note>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation addCandidate($input: AddCandidateInput!) {
  addCandidate(input: $input) {
    id
    name
    email
    phoneNumber
    jobId
    organizationId
    candidateStatus
    eligibility
    source
    candidateLocation
    candidateCompany
    role
    isStarred
    createdAt
    updatedAt
  }
}
```

## Error Responses

| Error Code | Description |
| --- | --- |
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The token does not include the write scope |
| BAD_USER_INPUT | Required fields are missing or malformed (e.g. `jobId` is not a valid UUID) |
| NOT_FOUND | The referenced job does not exist in the caller's tenant |
| INTERNAL_SERVER_ERROR | Unexpected server-side failure while creating the candidate |
