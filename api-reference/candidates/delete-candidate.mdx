## Overview

Soft-delete a candidate. The mutation sets a `deletedAt` marker on the candidate row (the underlying record remains in storage), which removes the candidate from all list and report surfaces going forward. Any downstream AI-interview row for the candidate is left in place, since reporting already filters on `deletedAt`. To remove many candidates in one call, use `bulkDeleteCandidates` instead.

<Warning>
This operation is irreversible and requires the destructive scope (Admin role). Deleted data cannot be recovered.
</Warning>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation deleteCandidate($id: UUID!) {
  deleteCandidate(id: $id)
}
```

## Request Parameters

<ParamField body="id" type="string" required>
  UUID of the candidate to soft-delete. Must belong to the caller's tenant.
</ParamField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid authentication credentials |
| FORBIDDEN | The caller lacks the destructive scope (Admin role) required for delete operations |
| BAD_USER_INPUT | The `id` variable is not a valid UUID |
| NOT_FOUND | No candidate with the given ID exists in the caller's tenant |
| INTERNAL_SERVER_ERROR | Unexpected server error while performing the delete |
