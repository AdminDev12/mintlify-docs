## Overview

Fetch one candidate row by its unique identifier. Use this operation to load a candidate's full profile — contact details, resume-derived fields, scoring, and pipeline state — after obtaining an ID from `candidates` or `candidatesByJob`. The query returns `null` when the row does not exist or belongs to a different tenant, so a missing candidate is indistinguishable from one outside your partition.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query GetCandidate($id: UUID!) {
  candidate(id: $id) {
    id
    name
    email
    phoneNumber
    jobId
    organizationId
    resumeScore
    candidateStatus
    eligibility
    source
    currentStageId
    skillsFound
    candidateLocation
    role
    summary
    linkedIn
    experienceStructured {
      role
      company
      startDate
      endDate
    }
    isStarred
    createdAt
    updatedAt
  }
}
```

## Request Parameters

<ParamField body="id" type="string" required>
  Unique identifier (UUID) of the candidate to fetch. Returns `null` if no candidate with this ID exists in your tenant.
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="candidate" type="object">
      The candidate record, or `null` if not found in your tenant.

      <Expandable title="candidate properties">
        <ResponseField name="id" type="string">
          Unique candidate identifier (UUID).
        </ResponseField>

        <ResponseField name="name" type="string">
          Candidate's full name.
        </ResponseField>

        <ResponseField name="email" type="string">
          Email address, if known.
        </ResponseField>

        <ResponseField name="phoneNumber" type="string">
          Phone number, if known.
        </ResponseField>

        <ResponseField name="jobId" type="string">
          Identifier of the job this candidate belongs to.
        </ResponseField>

        <ResponseField name="organizationId" type="string">
          Identifier of the owning organization.
        </ResponseField>

        <ResponseField name="resumeScore" type="number">
          Aggregate AI resume score. Null when the resume has not been scored.
        </ResponseField>

        <ResponseField name="candidateStatus" type="string">
          Lifecycle status in the hiring pipeline. One of `APPLIED`, `IN_PROGRESS`, `ADVANCED`, `REJECTED`, `HIRED`, `WITHDRAWN`. `APPLIED` is the initial state.
        </ResponseField>

        <ResponseField name="eligibility" type="string">
          Recruiter's eligibility decision — distinct from the lifecycle status. One of `ELIGIBLE`, `INELIGIBLE`, `UNSET`. Legacy rows without this field surface as `UNSET`.
        </ResponseField>

        <ResponseField name="source" type="string">
          Provenance of the candidate row. One of `MANUAL` (add-candidate form), `BULK_UPLOAD` (CSV/Excel ingest), `INTERNAL_POOL` (pool-to-job importer), `CAREERS_PAGE` (public application surface).
        </ResponseField>

        <ResponseField name="currentStageId" type="string">
          Identifier of the candidate's current pipeline stage.
        </ResponseField>

        <ResponseField name="skillsFound" type="array">
          Skills identified from the resume.
        </ResponseField>

        <ResponseField name="candidateLocation" type="string">
          Candidate's location, from resume extraction.
        </ResponseField>

        <ResponseField name="role" type="string">
          Candidate's current or most recent role.
        </ResponseField>

        <ResponseField name="summary" type="string">
          Two- to three-sentence professional summary, from resume extraction.
        </ResponseField>

        <ResponseField name="linkedIn" type="string">
          LinkedIn profile URL, when listed on the resume.
        </ResponseField>

        <ResponseField name="experienceStructured" type="array">
          Structured work history (companion to the free-form `experience` field).

          <Expandable title="ExperienceEntry">
            <ResponseField name="role" type="string">
              Job title held in this entry.
            </ResponseField>

            <ResponseField name="company" type="string">
              Employer name.
            </ResponseField>

            <ResponseField name="startDate" type="string">
              Start date of the entry, if known.
            </ResponseField>

            <ResponseField name="endDate" type="string">
              End date of the entry; null for a current position.
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="isStarred" type="boolean">
          Recruiter-marked standout candidate. Legacy rows without the field surface as `false`.
        </ResponseField>

        <ResponseField name="createdAt" type="string">
          ISO 8601 timestamp of creation.
        </ResponseField>

        <ResponseField name="updatedAt" type="string">
          ISO 8601 timestamp of the last update.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

| Error Code | Description |

| FORBIDDEN | The credentials are valid but lack access to this operation. |
| BAD_USER_INPUT | `id` is not a valid UUID. |
