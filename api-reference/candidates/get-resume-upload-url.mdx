## Overview

Request a presigned Azure Blob SAS URL (write-only, 15-minute expiry) that your client uses to PUT a resume file directly to storage, bypassing the API. This mutation only hands out the URL — the candidate row itself is created in a follow-up call to `addCandidate` (or via the bulk-upload Function), which references the uploaded file by the returned `blobPath`. The blob path is server-generated as `<tenantId>/Resumes/<random-uuid>.<ext>`, so callers cannot collide with another tenant's namespace or overwrite an existing resume.

<Note>
This operation requires the write scope.
</Note>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation GetResumeUploadUrl($input: ResumeUploadUrlInput!) {
  getResumeUploadUrl(input: $input) {
    uploadUrl
    blobPath
    expiresAt
  }
}
```

## Request Parameters

<ParamField body="jobId" type="string" required>
  UUID of the job the resume upload is associated with
</ParamField>

<ParamField body="fileName" type="string" required>
  Original file name; used for the blob extension and the content-disposition header
</ParamField>

<ParamField body="contentType" type="string" required>
  MIME type of the file. Must be one of `application/pdf`, `application/msword`, or `application/vnd.openxmlformats-officedocument.wordprocessingml.document`
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="getResumeUploadUrl" type="object">
      The presigned upload target

      <Expandable title="ResumeUploadUrl properties">
        <ResponseField name="uploadUrl" type="string">
          Write-only presigned SAS URL; PUT the file bytes directly to this URL before it expires
        </ResponseField>

        <ResponseField name="blobPath" type="string">
          Server-generated blob path (`<tenantId>/Resumes/<random-uuid>.<ext>`); pass this to subsequent calls such as `addCandidate`, bulk upload, or `analyzeResume` to reference the file
        </ResponseField>

        <ResponseField name="expiresAt" type="string">
          ISO 8601 timestamp when the upload URL stops working (15 minutes after issue)
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The token lacks the write scope required for this mutation |
| BAD_USER_INPUT | `contentType` is not one of the three allowed MIME types, or `jobId` is not a valid UUID |
| INTERNAL_SERVER_ERROR | Storage service failed to issue the presigned URL |
