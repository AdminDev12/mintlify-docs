## Overview

Copy candidates from your organization's internal pool into a specific job. Each source row is cloned with a fresh id, `source` set to `INTERNAL_POOL`, and `candidateStatus` set to `APPLIED`. Candidates are email-deduplicated within the target job, so duplicates surface as per-row failures with reason `duplicate_in_job` rather than failing the whole batch. Use the `internalPoolCandidates` query first to get ranked suggestions for the target job, then pass the chosen candidate ids to this mutation. A single `CANDIDATE_POOL_IMPORTED` audit event is emitted with the source ids and target job id.

<Note>
This operation requires the write scope.
</Note>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation ImportCandidatesFromPool($input: ImportCandidatesFromPoolInput!) {
  importCandidatesFromPool(input: $input) {
    copied {
      id
      name
      email
      jobId
      organizationId
      source
      candidateStatus
      eligibility
      resumeScore
      createdAt
    }
    failures {
      id
      reason
    }
  }
}
```

## Request Parameters

<ParamField body="sourceCandidateIds" type="array" required>
  Array of candidate UUIDs to copy from the internal pool. Each id must reference an existing candidate row in your organization (typically selected from the `internalPoolCandidates` query result)
</ParamField>

<ParamField body="targetJobId" type="string" required>
  UUID of the job the candidates should be imported into
</ParamField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The token lacks the write scope required for this mutation |
| BAD_USER_INPUT | `targetJobId` or a source candidate id is not a valid UUID, or the id list is empty |
| NOT_FOUND | The target job does not exist in your tenant |
| INTERNAL_SERVER_ERROR | Unexpected server-side failure while cloning candidate rows |
