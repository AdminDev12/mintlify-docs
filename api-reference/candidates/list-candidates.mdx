## Overview

Retrieve a paginated list of candidates across your tenant, with optional filtering by job, free-text search, and server-side sorting. This is the general-purpose candidate list; for a single job's full stack-ranked roster use `candidatesByJob`, and for a single record use `candidate`. The response envelope also carries a `pageInfo` object with pagination metadata alongside `items`.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query ListCandidates(
  $perPage: Int
  $pageNumber: Int
  $jobId: UUID
  $search: String
  $sortBy: CandidateSortField = CREATED_AT
  $sortDir: SortDirection = DESC
) {
  candidates(
    perPage: $perPage
    pageNumber: $pageNumber
    jobId: $jobId
    search: $search
    sortBy: $sortBy
    sortDir: $sortDir
  ) {
    items {
      id
      name
      email
      jobId
      resumeScore
      candidateStatus
      eligibility
      source
      candidateLocation
      role
      isStarred
      createdAt
    }
  }
}
```

## Request Parameters

<ParamField body="perPage" type="integer">
  Number of candidates to return per page.
</ParamField>

<ParamField body="pageNumber" type="integer">
  Page number to fetch.
</ParamField>

<ParamField body="jobId" type="string">
  Restrict results to candidates belonging to this job (UUID). Omit to list candidates across all jobs.
</ParamField>

<ParamField body="search" type="string">
  Free-text search term to filter candidates.
</ParamField>

<ParamField body="sortBy" type="CandidateSortField" default="CREATED_AT">
  Server-side sort field. One of `RESUME_SCORE`, `CREATED_AT`, `NAME`. `RESUME_SCORE` powers the stack-rank table.
</ParamField>

<ParamField body="sortDir" type="SortDirection" default="DESC">
  Sort direction. One of `ASC`, `DESC`.
</ParamField>

## Error Responses

| Error Code | Description |
| --- | --- |
| UNAUTHENTICATED | Missing or invalid API key or bearer token. |
| FORBIDDEN | The credentials are valid but lack access to this operation. |
| BAD_USER_INPUT | An argument is malformed, e.g. `jobId` is not a valid UUID or an unknown enum value was supplied. |
| INTERNAL_SERVER_ERROR | Unexpected server-side failure. |
