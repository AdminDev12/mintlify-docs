## Overview

Apply a PATCH-style edit to a candidate's editable identity and resume-derived fields (name, email, phone number, location, company, past companies, experience, education, role, and skills). Omitted fields are left untouched, explicit nulls clear a field, and at least one editable field must be supplied; the operation is idempotent — a patch whose values match the stored row produces no write and no audit entry, otherwise a `CANDIDATE_UPDATED` audit event captures the per-field before/after diff. Score fields are edited through `updateResumeScore`, and eligibility through `updateCandidateEligibility`; use `addCandidate` to create the row in the first place.

<Note>
This operation requires the **write** scope.
</Note>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation updateCandidate($input: UpdateCandidateInput!) {
  updateCandidate(input: $input) {
    id
    name
    email
    phoneNumber
    candidateLocation
    candidateCompany
    pastCompanies
    experience
    education
    role
    skillsFound
    candidateStatus
    updatedAt
  }
}
```

## Request Parameters

<ParamField body="id" type="string" required>
  UUID of the candidate to update
</ParamField>

<ParamField body="name" type="string">
  New full name for the candidate
</ParamField>

<ParamField body="email" type="string">
  New email address; pass `null` to clear
</ParamField>

<ParamField body="phoneNumber" type="string">
  New phone number; pass `null` to clear
</ParamField>

<ParamField body="candidateLocation" type="string">
  New candidate location; pass `null` to clear
</ParamField>

<ParamField body="candidateCompany" type="string">
  New current company; pass `null` to clear
</ParamField>

<ParamField body="pastCompanies" type="string">
  Free-form list of past companies; pass `null` to clear
</ParamField>

<ParamField body="experience" type="string">
  Free-form work-experience text; pass `null` to clear
</ParamField>

<ParamField body="education" type="string">
  Free-form education text; pass `null` to clear
</ParamField>

<ParamField body="role" type="string">
  New current role or title; pass `null` to clear
</ParamField>

<ParamField body="skillsFound" type="array">
  Replacement array of skill strings for the candidate
</ParamField>

<ParamField body="reason" type="string">
  Optional reason recorded alongside the audit event
</ParamField>

## Error Responses

| Error Code | Description |
| --- | --- |
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The token does not include the write scope |
| BAD_USER_INPUT | No editable field was supplied, or a value is malformed |
| NOT_FOUND | The candidate does not exist in the caller's tenant |
| INTERNAL_SERVER_ERROR | Unexpected server-side failure while applying the patch |
