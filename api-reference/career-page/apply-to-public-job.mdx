## Overview

Submit an application to a published job from the public careers page. The mutation creates a candidate record with source `CAREERS_PAGE` and status `APPLIED`, and returns the new candidate ID so your UI can redirect to a thank-you page. The call is idempotent on the combination of `orgSlug`, `jobId`, and applicant email: re-submitting the same email to the same job returns the existing candidate ID with `duplicate: true` and records no new audit event. Discover jobs to apply to with `careersPublicJobs` and `careersPublicJob`.

<Note>
This operation is part of the public career-page surface and is unauthenticated by design. Do not send `x-api-key` or `Authorization` headers with this request.
</Note>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation ApplyToPublicJob($input: ApplyToPublicJobInput!) {
  applyToPublicJob(input: $input) {
    candidateId
    duplicate
  }
}
```

## Request Parameters

<ParamField body="orgSlug" type="string" required>
  Organization slug taken from the careers-page URL (for example, `/careers/acme` yields `acme`).
</ParamField>

<ParamField body="jobId" type="string" required>
  UUID of the job being applied to. The job must exist, be published, and belong to the organization identified by `orgSlug`; any mismatch returns a generic `BAD_USER_INPUT` error so no existence information leaks.
</ParamField>

<ParamField body="applicantFullName" type="string" required>
  Full name of the applicant.
</ParamField>

<ParamField body="applicantEmail" type="string" required>
  Email address of the applicant. Used as the idempotency key together with `orgSlug` and `jobId`.
</ParamField>

<ParamField body="applicantPhoneNumber" type="string">
  Phone number of the applicant.
</ParamField>

<ParamField body="coverLetter" type="string">
  Optional cover letter or pitch (maximum 5,000 characters).
</ParamField>

<ParamField body="resumeText" type="string">
  Optional resume text dump extracted client-side (maximum 50,000 characters).
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="applyToPublicJob" type="object">
      <Expandable title="ApplyToPublicJobResult properties">
        <ResponseField name="candidateId" type="string">
          UUID of the candidate record. For a first-time application this is the newly created candidate; on a duplicate submission it is the existing candidate for the same email and job.
        </ResponseField>

        <ResponseField name="duplicate" type="boolean">
          True when this email address already applied to the same job. The existing candidate ID is returned and no new record or audit event is created.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| BAD_USER_INPUT | A required field is missing or malformed, a length limit is exceeded (`coverLetter` over 5,000 characters, `resumeText` over 50,000 characters), or the job does not exist, is not published, or does not belong to `orgSlug`. The mismatch cases return the same generic error so no existence information leaks. |
| INTERNAL_SERVER_ERROR | An unexpected server-side failure occurred. Retry the request; the operation is idempotent per applicant email and job. |
