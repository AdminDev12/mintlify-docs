## Overview

Retrieve the detail projection of a single published job for rendering a per-job page on the public careers site. The result is a superset of the `careersPublicJobs` listing card, adding the job description body, required skills, and notice period — internal recruiter-facing fields remain excluded. The operation returns null when the job does not exist, does not belong to the given `orgSlug`, or is not published; all three cases produce the same null shape so no cross-tenant existence information leaks. Pair it with `applyToPublicJob` to submit a candidate application.

<Note>
This operation is part of the public career-page surface and is unauthenticated by design. Do not send `x-api-key` or `Authorization` headers with this request.
</Note>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query CareersPublicJob($orgSlug: String!, $jobId: UUID!) {
  careersPublicJob(orgSlug: $orgSlug, jobId: $jobId) {
    jobId
    title
    type
    location
    city
    noOfOpenings
    minimumExperience
    maximumExperience
    ctc
    noticePeriod
    jobDescription
    skills {
      skillName
      skillLevel
      requirementType
    }
    publishedAt
  }
}
```

## Request Parameters

<ParamField body="orgSlug" type="string" required>
  Organization slug taken from the careers-page URL (for example, `/careers/acme` yields `acme`).
</ParamField>

<ParamField body="jobId" type="string" required>
  UUID of the job to fetch. The job must be published and belong to the organization identified by `orgSlug`; otherwise the operation returns null.
</ParamField>

  -H "Content-Type: application/json" \
  -d '{

      "orgSlug": "acme",

  }'

## Error Responses

| Error Code | Description |
|------------|-------------|
| BAD_USER_INPUT | A variable is missing or malformed (for example, `jobId` is not a valid UUID). Note that an unknown or unpublished job does not error — it returns `careersPublicJob: null`. |
| INTERNAL_SERVER_ERROR | An unexpected server-side failure occurred. Retry the request. |
