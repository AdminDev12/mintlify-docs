## Overview

Retrieve the listing-card view of every job an organization has published to its public careers page (`/careers/{orgSlug}`). Only jobs whose status is `PUBLISHED` and that have `publishToCareersPage` enabled are returned; internal recruiter-facing fields are stripped from the projection at the resolver. Use this operation to render a careers-page job board, then fetch a single job's full detail with `careersPublicJob` and submit applications with `applyToPublicJob`.

<Note>
This operation is part of the public career-page surface and is unauthenticated by design. Do not send `x-api-key` or `Authorization` headers with this request.
</Note>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query CareersPublicJobs($orgSlug: String!) {
  careersPublicJobs(orgSlug: $orgSlug) {
    jobId
    title
    type
    location
    city
    noOfOpenings
    minimumExperience
    maximumExperience
    ctc
    publishedAt
  }
}
```

## Request Parameters

<ParamField body="orgSlug" type="string" required>
  Organization slug taken from the careers-page URL (for example, `/careers/acme` yields `acme`). If the organization does not exist or has no public jobs, the operation returns an empty array rather than an error or null.
</ParamField>

## Request Example

<CodeGroup>

```bash cURL
curl -X POST https://api.exterview.ai/graphql \
  -H "Content-Type: application/json" \
  -d '{
    "query": "query CareersPublicJobs($orgSlug: String!) { careersPublicJobs(orgSlug: $orgSlug) { jobId title type location city noOfOpenings minimumExperience maximumExperience ctc publishedAt } }",
    "variables": {
      "orgSlug": "acme"
    }
  }'
```

```javascript JavaScript
const query = `
  query CareersPublicJobs($orgSlug: String!) {
    careersPublicJobs(orgSlug: $orgSlug) {
      jobId
      title
      type
      location
      city
      noOfOpenings

const variables = {
  orgSlug: "acme"

const response = await fetch('https://api.exterview.ai/graphql', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ query, variables })
});

const data = await response.json();
```

```python Python
import requests

url = "https://api.exterview.ai/graphql"
headers = {
    "Content-Type": "application/json"
}

query = """
query CareersPublicJobs($orgSlug: String!) {
  careersPublicJobs(orgSlug: $orgSlug) {
    jobId
    title
    type
    location
    city
    noOfOpenings
    minimumExperience
    maximumExperience
    ctc
    publishedAt
  }
}
"""

variables = {
    "orgSlug": "acme"
}

response = requests.post(url, headers=headers, json={"query": query, "variables": variables})
print(response.json())
```

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="careersPublicJobs" type="array">
      Array of public job listings. Always an array — empty when the organization does not exist or has no public jobs, never null.

      <Expandable title="PublicJobListing object">
        <ResponseField name="jobId" type="string">
          Unique identifier (UUID) of the job.
        </ResponseField>

        <ResponseField name="title" type="string">
          Job title.
        </ResponseField>

        <ResponseField name="type" type="string">
          Work arrangement for the role, such as "Hybrid", "Remote", or "OnSite". May be null.
        </ResponseField>

        <ResponseField name="location" type="string">
          Region of the role. May be null.
        </ResponseField>

        <ResponseField name="city" type="string">
          City of the role. May be null.
        </ResponseField>

        <ResponseField name="noOfOpenings" type="string">
          Number of open positions for this job. May be null.
        </ResponseField>

        <ResponseField name="minimumExperience" type="string">
          Minimum experience required. May be null.
        </ResponseField>

        <ResponseField name="maximumExperience" type="string">
          Maximum experience considered. May be null.
        </ResponseField>

        <ResponseField name="ctc" type="string">
          Compensation for the role. May be null.
        </ResponseField>

        <ResponseField name="publishedAt" type="string">
          ISO 8601 timestamp of when the job was published.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| BAD_USER_INPUT | The `orgSlug` variable is missing or not a string. Note that an unknown organization slug does not error — it returns an empty array. |
| INTERNAL_SERVER_ERROR | An unexpected server-side failure occurred. Retry the request. |
