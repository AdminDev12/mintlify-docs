## Overview

Poll the status of an asynchronous bulk resume upload started via `POST /api/candidates/bulk-upload-resumes`. The upload endpoint returns a `jobId` immediately; use this endpoint to track parsing, scoring, and candidate creation progress until the job finishes. This REST endpoint mirrors the `getBulkUploadJob` GraphQL query and returns the same job shape.

<Info>
  Exterview does not send outbound webhooks for bulk upload jobs. Poll this
  endpoint until `status` reaches a terminal state — `COMPLETED` or `FAILED`.
  Non-terminal states are `PENDING` and `PROCESSING`.
</Info>

## Endpoint

```
GET /api/candidates/bulk-upload-status/{jobId}
```

## Path Parameters

<ParamField path="jobId" type="string" required>
  Unique identifier (UUID) of the bulk upload job, returned by `POST /api/candidates/bulk-upload-resumes`
</ParamField>

## Request Example

<CodeGroup>

```bash cURL
curl -X GET https://api.exterview.ai/api/candidates/bulk-upload-status/6f1c2a9e-4b7d-4f3a-9c2e-8d5b1a7e3f60 \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```javascript JavaScript
const jobId = '6f1c2a9e-4b7d-4f3a-9c2e-8d5b1a7e3f60';

const response = await fetch(
  `https://api.exterview.ai/api/candidates/bulk-upload-status/${jobId}`,
  {
    method: 'GET',
    headers: {
      'x-api-key': 'YOUR_API_KEY',
      'Authorization': 'Bearer YOUR_TOKEN'
    }
  }
);

const job = await response.json();

if (job.status === 'COMPLETED' || job.status === 'FAILED') {
  console.log('Job finished:', job);
}
```

```python Python
import requests

job_id = "6f1c2a9e-4b7d-4f3a-9c2e-8d5b1a7e3f60"
url = f"https://api.exterview.ai/api/candidates/bulk-upload-status/{job_id}"
headers = {
    "x-api-key": "YOUR_API_KEY",
    "Authorization": "Bearer YOUR_TOKEN"
}

response = requests.get(url, headers=headers)
job = response.json()

if job["status"] in ("COMPLETED", "FAILED"):
    print("Job finished:", job)
```

</CodeGroup>

## Response

<ResponseField name="id" type="string">
  Unique identifier (UUID) of the bulk upload job
</ResponseField>

<ResponseField name="targetJobId" type="string">
  ID of the job (requisition) the uploaded candidates are associated with
</ResponseField>

<ResponseField name="status" type="string">
  Lifecycle state of the job: `PENDING`, `PROCESSING`, `COMPLETED`, or `FAILED`
</ResponseField>

<ResponseField name="total" type="integer">
  Total number of resume files submitted in the upload
</ResponseField>

<ResponseField name="processed" type="integer">
  Number of files processed so far
</ResponseField>

<ResponseField name="succeeded" type="integer">
  Number of files that produced a candidate successfully
</ResponseField>

<ResponseField name="failed" type="integer">
  Number of files that failed processing
</ResponseField>

<ResponseField name="duplicates" type="integer">
  Number of duplicate candidates skipped
</ResponseField>

<ResponseField name="createdCandidateIds" type="string[]">
  IDs of the candidates created by this job
</ResponseField>

<ResponseField name="failures" type="array">
  Per-file failures surfaced back to the recruiter

  <Expandable title="Failure Object">
    <ResponseField name="fileName" type="string">
      Name of the file that failed
    </ResponseField>

    <ResponseField name="stage" type="string">
      Pipeline stage where the failure occurred: `upload`, `extract`, `classify`, `score`, or `write`
    </ResponseField>

    <ResponseField name="reason" type="string">
      Human-readable reason for the failure
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="startedAt" type="string | null">
  Timestamp when processing started; `null` while the job is still `PENDING`
</ResponseField>

<ResponseField name="completedAt" type="string | null">
  Timestamp when the job reached a terminal state; `null` until then
</ResponseField>

<ResponseField name="error" type="string | null">
  Job-level error message when `status` is `FAILED`; `null` otherwise
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp when the job was created
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Timestamp when the job record was last updated
</ResponseField>

## Error Responses

| Status Code | Description |
|-------------|-------------|
| 401 | Missing or invalid API key or token |
| 404 | No bulk upload job with the given `jobId` exists for the caller's organization |
