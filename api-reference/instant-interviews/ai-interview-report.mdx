## Overview

`aiInterviewReport` returns the recruiter-facing post-interview report for a candidate's AI interview, including status, interview mode, timing, recording links, the full transcript, and the AI-generated analysis. Use it after a candidate finishes an interview to review the outcome. The mode-specific siblings `voiceInterviewReport` and `avatarInterviewReport` return the same shape filtered to a single interview mode. This operation is restricted to Admin and Recruiter roles.

<Info>
  Exterview has no customer-facing outbound webhooks. To retrieve interview results, poll this operation after the interview completes until the report is available and `analysis.status` indicates the analysis has finished.
</Info>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query AiInterviewReport($candidateId: String!) {
  aiInterviewReport(candidateId: $candidateId) {
    id
    candidateId
    jobId
    status
    mode
    startedAt
    completedAt
    recordingUrl
    thumbnailUrl
    transcript {
      role
      text
      at
    }
    analysis {
      status
      fitScore
      candidateFitCategory
      criticalConcerns
      feedback
      strength
      weakness
    }
  }
}
```

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="aiInterviewReport" type="object">

            <ResponseField name="feedback" type="string">

            <ResponseField name="strength" type="string">
              Summary of the candidate's strengths.
            </ResponseField>
            <ResponseField name="weakness" type="string">
              Summary of the candidate's weaknesses.

          </Expandable>

      </Expandable>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | The request is missing valid authentication credentials. |
| FORBIDDEN | The authenticated principal lacks the Admin or Recruiter role. |
| BAD_USER_INPUT | The `candidateId` argument is missing or malformed. |
| NOT_FOUND | No candidate exists with the supplied `candidateId`. |
| INTERNAL_SERVER_ERROR | An unexpected error occurred while resolving the report. |
