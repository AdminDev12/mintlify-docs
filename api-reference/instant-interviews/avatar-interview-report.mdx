## Overview

`avatarInterviewReport` is a focused avatar-mode read that returns the same report shape as `voiceInterviewReport` but only matches interviews conducted in `AVATAR` mode. It exposes the interview status, timing, recording links, full transcript, and AI-generated analysis, and clients select only the fields they need. Use `aiInterviewReport` when the interview mode is not known in advance. This operation is restricted to Admin and Recruiter roles.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query AvatarInterviewReport($candidateId: String!) {
  avatarInterviewReport(candidateId: $candidateId) {
    id
    candidateId
    jobId
    status
    mode
    startedAt
    completedAt
    recordingUrl
    thumbnailUrl
    transcript {
      role
      text
      at
    }
    analysis {
      status
      fitScore
      candidateFitCategory
      criticalConcerns
      feedback
      strength
      weakness
    }
  }
}
```

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="avatarInterviewReport" type="object">
      Null when the candidate has no avatar-mode interview report.
      <Expandable title="avatarInterviewReport properties">
        <ResponseField name="id" type="string" required>
          Unique identifier (UUID) of the interview record.
        </ResponseField>
        <ResponseField name="candidateId" type="string" required>
          Identifier of the candidate the report belongs to.
        </ResponseField>
        <ResponseField name="jobId" type="string" required>
          Identifier of the job the interview was conducted for.
        </ResponseField>
        <ResponseField name="status" type="string" required>
          Interview status. One of `SCHEDULED`, `STARTED`, `COMPLETED`, `EXPIRED`.
        </ResponseField>

          Interview mode. One of `AVATAR`, `VOICE`. Always `AVATAR` for this operation.
        </ResponseField>
        <ResponseField name="startedAt" type="string">

        </ResponseField>
        <ResponseField name="completedAt" type="string">

        </ResponseField>
        <ResponseField name="recordingUrl" type="string">
          URL of the interview recording, when available.
        </ResponseField>
        <ResponseField name="thumbnailUrl" type="string">

            </ResponseField>
            <ResponseField name="at" type="string" required>

        </ResponseField>
        <ResponseField name="analysis" type="object" required>

            <ResponseField name="candidateFitCategory" type="string">
              Categorical fit assessment for the candidate.
            </ResponseField>
            <ResponseField name="criticalConcerns" type="array">
              List of critical concerns flagged by the analysis.
            </ResponseField>
            <ResponseField name="feedback" type="string">
              Narrative feedback on the candidate's performance.
            </ResponseField>
            <ResponseField name="strength" type="string">
              Summary of the candidate's strengths.
            </ResponseField>
            <ResponseField name="weakness" type="string">
              Summary of the candidate's weaknesses.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | The request is missing valid authentication credentials. |
| FORBIDDEN | The authenticated principal lacks the Admin or Recruiter role. |
| BAD_USER_INPUT | The `candidateId` argument is missing or malformed. |
| NOT_FOUND | No candidate exists with the supplied `candidateId`. |
| INTERNAL_SERVER_ERROR | An unexpected error occurred while resolving the report. |
