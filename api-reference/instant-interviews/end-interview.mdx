## Overview

End an in-progress AI interview for a candidate, marking the session complete and optionally attaching a thumbnail image captured during the conversation. Call this when the interview client finishes or the candidate leaves the session that was created with `startAiInterview`. Completing the interview makes it eligible for analysis, which can be re-run later with `reanalyzeAiInterview`.

<Note>
  This operation requires the write scope.
</Note>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation endAiInterview($candidateId: String!, $thumbnailUrl: String) {
  endAiInterview(candidateId: $candidateId, thumbnailUrl: $thumbnailUrl)
}
```

## Request Parameters

<ParamField body="candidateId" type="string" required>
  Identifier of the candidate whose AI interview should end
</ParamField>

<ParamField body="thumbnailUrl" type="string">
  Optional URL of a thumbnail image captured during the session, stored on the interview record
</ParamField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The authenticated principal lacks the write scope |
| BAD_USER_INPUT | Invalid input, such as a malformed `thumbnailUrl` or an interview that is not currently in progress |
| NOT_FOUND | No candidate or active interview exists for the supplied `candidateId` |
| INTERNAL_SERVER_ERROR | Unexpected server error while ending the interview session |
