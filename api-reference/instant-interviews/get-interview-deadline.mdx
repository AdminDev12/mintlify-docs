## Overview

`aiInterviewDeadline` returns the deadline for a candidate's AI interview along with flags indicating whether the deadline has passed and whether the interview has already been completed. Use it before presenting the interview experience to decide whether the candidate can still start, and to render organization branding (name and logo) on the interview landing screen. Once the interview is complete, use `aiInterviewReport` to retrieve the full results.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query AiInterviewDeadline($candidateId: String!) {
  aiInterviewDeadline(candidateId: $candidateId) {
    aiInterviewDeadline
    isExpired
    isInterviewCompleted
    organizationName
    organizationLogo
  }
}
```

## Request Parameters

<ParamField body="candidateId" type="string" required>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | The request is missing valid authentication credentials. |
| BAD_USER_INPUT | The `candidateId` argument is missing or malformed. |
| NOT_FOUND | No candidate exists with the supplied `candidateId`. |
| INTERNAL_SERVER_ERROR | An unexpected error occurred while resolving the deadline. |
