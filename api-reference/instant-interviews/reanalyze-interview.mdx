## Overview

Re-run analysis for an already-completed AI interview. This recruiter-facing operation queues a fresh analysis pass over the interview's transcript and recording, replacing the previous results. Use it when an earlier analysis failed or when you want updated scoring; the refreshed output is then available through `aiInterviewReport`.

<Note>
  This operation requires the write scope.
</Note>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation reanalyzeAiInterview($candidateId: String!) {
  reanalyzeAiInterview(candidateId: $candidateId)
}
```

## Request Parameters

<ParamField body="candidateId" type="string" required>
  Identifier of the candidate whose completed AI interview should be reanalyzed
</ParamField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The authenticated principal lacks the Admin or Recruiter role, or the write scope |
| BAD_USER_INPUT | The candidate's interview is not in a completed state and cannot be reanalyzed |
| NOT_FOUND | No completed interview exists for the supplied `candidateId` |
| INTERNAL_SERVER_ERROR | Unexpected server error while queuing the reanalysis |
