## Overview

Dispatch AI-interview invite emails to a selected set of candidates for a specific job. Each invited candidate receives a link to complete an AI interview in the chosen mode before the deadline you specify. Use this recruiter-facing operation to kick off screening at scale; candidates then launch their sessions through `startAiInterview`, and results are collected per candidate.

<Warning>
  This operation requires the billing/comms-impacting scope because it sends real communications to candidates and incurs usage costs.
</Warning>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation sendAiInterviewInvites($input: SendAiInterviewInvitesInput!) {
  sendAiInterviewInvites(input: $input) {
    total
    sent
    failed
    failedCandidateIds
  }
}
```

## Request Parameters

<ParamField body="jobId" type="string" required>
  Identifier of the job the candidates are being interviewed for
</ParamField>

<ParamField body="candidateIds" type="array" required>
  List of candidate identifiers to invite. Each candidate receives an individual invite email.
</ParamField>

<ParamField body="aiInterviewDeadline" type="string" required>
  DateTime (ISO 8601) by which candidates must complete the AI interview. Invites for candidates who do not finish by this time expire.
</ParamField>

<ParamField body="interviewMode" type="InterviewMode" required>
  Interview mode for the invited candidates. Allowed values: `AVATAR`, `VOICE`.
</ParamField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The authenticated principal lacks the Admin or Recruiter role, or the billing/comms-impacting scope |
| BAD_USER_INPUT | Invalid input, such as an empty `candidateIds` list, a malformed `aiInterviewDeadline`, or an unknown `interviewMode` |
| NOT_FOUND | The job or one of the referenced candidates does not exist |
| INTERNAL_SERVER_ERROR | Unexpected server error while dispatching invites |
