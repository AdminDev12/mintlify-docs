## Overview

Start an AI interview for a candidate and receive everything the interview client needs to run the session: the conversation URL, the allotted interview time, job and candidate display details, and org branding. The interview mode defaults to `AVATAR`; `VOICE` skips Tavus provisioning and instead returns a `systemPrompt` so the browser can run its own STT/LLM/TTS loop. Sessions are typically ended with `endAiInterview` once the conversation finishes.

<Warning>
  This operation requires the billing/comms-impacting scope because starting a live AI interview session incurs usage costs.
</Warning>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation startAiInterview($candidateId: String!, $mode: InterviewMode) {
  startAiInterview(candidateId: $candidateId, mode: $mode) {
    conversationUrl
    interviewTimeInSeconds
    jobTitle
    jobId
    candidate {
      fullName
      role
      avatarUrl
    }
    organizationLogo
    organizationName
    systemPrompt
    mode
    voiceId
  }
}
```

## Request Parameters

<ParamField body="candidateId" type="string" required>
  Identifier of the candidate whose AI interview should start
</ParamField>

<ParamField body="mode" type="InterviewMode">
  Interview mode for the session. Allowed values: `AVATAR`, `VOICE`. When omitted, the mode defaults to `AVATAR`. `VOICE` skips Tavus provisioning and returns a `systemPrompt` for the browser to run its own STT/LLM/TTS loop.
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="startAiInterview" type="object">
      <Expandable title="startAiInterview properties">
        <ResponseField name="conversationUrl" type="string">
          URL of the live conversation session the interview client should join

        <ResponseField name="jobTitle" type="string">

        </ResponseField>

        <ResponseField name="jobId" type="string">
          Identifier of the job the candidate is interviewing for
        </ResponseField>

        <ResponseField name="candidate" type="object">

          <Expandable title="candidate properties">
            <ResponseField name="fullName" type="string">
              Candidate's full name
            </ResponseField>

            <ResponseField name="role" type="string">
              Role the candidate is being interviewed for
            </ResponseField>

            <ResponseField name="avatarUrl" type="string">
              URL of the candidate's avatar image
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="organizationLogo" type="string">
          URL of the hiring organization's logo
        </ResponseField>

        <ResponseField name="organizationName" type="string">
          Name of the hiring organization
        </ResponseField>

        <ResponseField name="systemPrompt" type="string">
          System prompt for the AI interviewer. Returned for `VOICE` mode so the browser can run its own STT/LLM/TTS loop.
        </ResponseField>

        <ResponseField name="mode" type="string">
          Interview mode for this session. One of `AVATAR`, `VOICE`.
        </ResponseField>

        <ResponseField name="voiceId" type="string">
          `VOICE` mode only — the org's selected ElevenLabs voice_id (Setup → Config). The candidate app initializes its TTS with this; `null` means the client default is used.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The authenticated principal lacks the billing/comms-impacting scope |
| BAD_USER_INPUT | Invalid input, such as an unknown `mode` value or an interview that is not in a startable state |
| NOT_FOUND | No candidate exists with the supplied `candidateId` |
| INTERNAL_SERVER_ERROR | Unexpected server error while provisioning the interview session |
