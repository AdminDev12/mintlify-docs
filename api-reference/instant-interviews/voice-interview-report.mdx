## Overview

`voiceInterviewReport` is a focused voice-mode read that mirrors `aiInterviewReport` but only matches interviews conducted in `VOICE` mode, so a recruiter interface built around voice screening never accidentally surfaces an avatar interview. It returns the same report shape — status, timing, transcript, and AI analysis — and clients select only the fields they need. Use `avatarInterviewReport` for the equivalent avatar-mode read. This operation is restricted to Admin and Recruiter roles.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query VoiceInterviewReport($candidateId: String!) {
  voiceInterviewReport(candidateId: $candidateId) {
    id
    candidateId
    jobId
    status
    mode
    startedAt
    completedAt
    recordingUrl
    thumbnailUrl
    transcript {
      role
      text
      at
    }
    analysis {
      status
      fitScore
      candidateFitCategory
      criticalConcerns
      feedback
      strength
      weakness
    }
  }
}
```

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | The request is missing valid authentication credentials. |
| FORBIDDEN | The authenticated principal lacks the Admin or Recruiter role. |
| BAD_USER_INPUT | The `candidateId` argument is missing or malformed. |
| NOT_FOUND | No candidate exists with the supplied `candidateId`. |
| INTERNAL_SERVER_ERROR | An unexpected error occurred while resolving the report. |
