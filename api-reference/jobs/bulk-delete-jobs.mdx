## Overview

Soft-delete multiple jobs in one call by passing an array of job UUIDs; each successfully deleted job has its `deletedAt` timestamp set. The mutation returns the IDs that were actually soft-deleted — IDs that do not exist in the caller's organization are skipped silently rather than failing the batch. To remove a single job, use the sibling `deleteJob` mutation; to stop accepting candidates without deleting, use `closeJob`.

<Warning>
  This operation is irreversible and requires the destructive scope (Admin role). Deleted data cannot be recovered.
</Warning>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation bulkDeleteJobs($ids: [UUID!]!) {
  bulkDeleteJobs(ids: $ids)
}
```

The mutation returns a list of UUID scalars, so no selection set is required. Compare the returned list against your input to detect IDs that were skipped.

## Request Parameters

<ParamField body="ids" type="array" required>
  Array of job UUIDs to soft-delete. All jobs must belong to the caller's organization; the operation is tenant-scoped. IDs that do not exist for the caller's tenant are skipped silently and omitted from the returned list.
</ParamField>

| Error Code | Description |
| --- | --- |
| `UNAUTHENTICATED` | Missing or invalid API key or bearer token. |
