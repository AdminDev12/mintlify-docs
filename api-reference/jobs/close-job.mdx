## Overview

Close a job, setting its lifecycle status to `CLOSED`. Use this when a position has been filled or is no longer being hired for. Because the unauthenticated `careersPublicJobs` query only returns jobs in `PUBLISHED` status, a closed job immediately disappears from the organization's public careers page; the job record itself is retained (use `deleteJob` for removal).

<Note>
This operation requires the `write` scope.
</Note>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation CloseJob($id: UUID!) {
  closeJob(id: $id) {
    id
    uid
    title
    status
    publishToCareersPage
    updatedAt
  }
}
```

## Request Parameters

<ParamField body="id" type="string" required>
  UUID of the job to close. The job must belong to the caller's tenant.
</ParamField>

## Error Responses

| Error Code | Description |
| --- | --- |
| UNAUTHENTICATED | Missing or invalid API key or bearer token. |
| FORBIDDEN | The caller lacks the Recruiter or Admin role, or the `write` scope. |
| BAD_USER_INPUT | `id` is missing or is not a valid UUID. |
| NOT_FOUND | No job with the given `id` exists for the caller's tenant. |
| INTERNAL_SERVER_ERROR | Unexpected server-side failure while closing the job. |
