## Overview

Create a new job in your organization from a title and a job description. The job is created in `DRAFT` status and is scoped to your tenant; use it as the starting point before enriching the record with `updateJob`, generating a questionnaire, and going live with `publishJob`. For the wizard-style single-call flow that creates and fills a job in one request, see `saveJobDetails`.

<Note>
This operation requires the `write` scope.
</Note>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation CreateJob($input: CreateJobInput!) {
  createJob(input: $input) {
    id
    uid
    tenantId
    title
    category
    status
    questionsStatus
    jobDescription
    createdAt
    updatedAt
  }
}
```

## Request Parameters

<ParamField body="title" type="string" required>
  Title of the job (for example, "Senior Backend Engineer").
</ParamField>

<ParamField body="description" type="string" required>
  Full job description text used as the basis for the job posting.
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="createJob" type="object">
      <Expandable title="createJob properties">
        <ResponseField name="id" type="string">
          Unique job identifier (UUID).
        </ResponseField>

        <ResponseField name="uid" type="string">
          Friendly per-tenant job code (for example, JOB-79BB). Uses the job code when set, otherwise derives a stable JOB-XXXX suffix from the UUID.
        </ResponseField>

        <ResponseField name="tenantId" type="string">
          UUID of the tenant (organization) that owns the job.
        </ResponseField>

        <ResponseField name="title" type="string">
          Job title.
        </ResponseField>

        <ResponseField name="category" type="string">
          Derived job category.
        </ResponseField>

        <ResponseField name="status" type="string">
          Job lifecycle status. One of `DRAFT`, `PUBLISHED`, `CLOSED`. Newly created jobs start in `DRAFT`.
        </ResponseField>

        <ResponseField name="questionsStatus" type="string">
          Status of the LLM-generated questionnaire for this job.
        </ResponseField>

        <ResponseField name="jobDescription" type="string">
          Full job description text.
        </ResponseField>

        <ResponseField name="createdAt" type="string">
          ISO 8601 timestamp when the job was created.
        </ResponseField>

        <ResponseField name="updatedAt" type="string">
          ISO 8601 timestamp when the job was last updated.

      </Expandable>

## Error Responses

| Error Code | Description |
| --- | --- |
| UNAUTHENTICATED | Missing or invalid API key or bearer token. |
| FORBIDDEN | The caller lacks the Recruiter or Admin role, or the `write` scope. |
| BAD_USER_INPUT | `title` or `description` is missing or fails validation. |
| INTERNAL_SERVER_ERROR | Unexpected server-side failure while creating the job. |
