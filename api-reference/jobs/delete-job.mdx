## Overview

Delete one job, identified by its UUID, from the caller's organization. Use this operation when a single job posting must be removed entirely rather than closed; to stop accepting candidates while keeping the job's history, use `closeJob` instead. To remove several jobs in one call, use the sibling `bulkDeleteJobs` mutation.

<Warning>
  This operation is irreversible and requires the destructive scope (Admin role). Deleted data cannot be recovered.
</Warning>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation deleteJob($id: UUID!) {
  deleteJob(id: $id)
}
```

The mutation returns a boolean scalar, so no selection set is required. A response of `true` confirms the job was deleted.

## Request Parameters

<ParamField body="id" type="string" required>
  UUID of the job to delete. The job must belong to the caller's organization; the operation is tenant-scoped.
</ParamField>

## Error Responses

| Error Code | Description |
| --- | --- |
| `UNAUTHENTICATED` | Missing or invalid API key or bearer token. |
| `FORBIDDEN` | The caller is authenticated but lacks the Admin role required for destructive operations. |
| `BAD_USER_INPUT` | The `id` variable is missing or is not a valid UUID. |
| `NOT_FOUND` | No job with the given ID exists in the caller's organization. |
| `INTERNAL_SERVER_ERROR` | An unexpected server-side failure occurred; retry the request. |
