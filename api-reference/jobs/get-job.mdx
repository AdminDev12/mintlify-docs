## Overview

The `job` query returns the full record for a single job in the caller's tenant, including the description, compensation details, required skills, AI-screening settings, and Agent Interview scoring weights. Use it to render a job detail view or to rehydrate the Create Job wizard — `jobFormOptions` is designed to be fired in the same GraphQL document so the wizard hydrates in a single round-trip. To browse many jobs at once, use the paginated `jobs` query instead.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query GetJob($id: UUID!) {
  job(id: $id) {
    id
    uid
    title
    category
    type
    location
    city
    jobDescription
    noOfOpenings
    minimumExperience
    maximumExperience
    ctc
    ctcCurrency
    noticePeriod
    status
    department
    employmentType
    resumeScoreThreshold
    agentRecommendation
    skills {
      skillName
      skillLevel
      requirementType
    }
    scoring {
      categories {
        name
        weight
      }
    }
    createdAt
    updatedAt
  }
}
```

## Request Parameters

<ParamField body="id" type="string" required>
  UUID of the job to retrieve. The job must belong to the caller's tenant.
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="job" type="object">
      The job record, or `null` when no matching job exists.

      <Expandable title="job properties">
        <ResponseField name="id" type="string">
          Unique job identifier (UUID).
        </ResponseField>
        <ResponseField name="uid" type="string">
          Friendly per-tenant job code (for example `JOB-79BB`). Uses the stored job code when set, otherwise derives a stable `JOB-XXXX` suffix from the UUID.
        </ResponseField>
        <ResponseField name="title" type="string">
          Job title.
        </ResponseField>
        <ResponseField name="category" type="string">
          LLM-derived job category. Distinct from the recruiter-picked `department`.
        </ResponseField>
        <ResponseField name="type" type="string">
          Work type: `Hybrid`, `Remote`, or `OnSite`. May be `null`.
        </ResponseField>
        <ResponseField name="location" type="string">
          Region (`APAC`, `EMEA`, or `AMERICAS`). May be `null`.
        </ResponseField>
        <ResponseField name="city" type="string">
          City where the role is based. May be `null`.
        </ResponseField>
        <ResponseField name="jobDescription" type="string">
          Full job description body. May be `null`.
        </ResponseField>
        <ResponseField name="noOfOpenings" type="string">
          Number of open positions. May be `null`.
        </ResponseField>
        <ResponseField name="minimumExperience" type="string">
          Minimum years of experience required. May be `null`.
        </ResponseField>
        <ResponseField name="maximumExperience" type="string">
          Maximum years of experience considered. May be `null`.
        </ResponseField>
        <ResponseField name="ctc" type="string">
          Compensation for the role. May be `null`.
        </ResponseField>
        <ResponseField name="ctcCurrency" type="string">
          ISO 4217 currency for `ctc`: `INR`, `USD`, or `EUR`. Null on legacy rows.
        </ResponseField>
        <ResponseField name="noticePeriod" type="string">
          Expected notice period. May be `null`.
        </ResponseField>
        <ResponseField name="status" type="string">
          Job status. One of the `JobStatus` enum values: `DRAFT`, `PUBLISHED`, `CLOSED`.
        </ResponseField>
        <ResponseField name="department" type="string">
          Recruiter-picked department (for example `engineering`). Null on legacy rows.
        </ResponseField>
        <ResponseField name="employmentType" type="string">
          Employment type: `full-time`, `part-time`, `contract`, or `internship`. Null on legacy rows.
        </ResponseField>
        <ResponseField name="resumeScoreThreshold" type="integer">
          Minimum AI-derived resume score (0-100) below which a candidate is auto-rejected at screening. Null on legacy jobs created before the field shipped.
        </ResponseField>
        <ResponseField name="agentRecommendation" type="integer">
          Recruiter-selected AI screening confidence band. Restricted to the picker values 95, 85, 77, 72, 65, 55, or 40. Null on legacy rows.
        </ResponseField>
        <ResponseField name="skills" type="array">
          Required skills for the job.
          <Expandable title="Skill Object">
            <ResponseField name="skillName" type="string">
              Name of the skill.
            </ResponseField>
            <ResponseField name="skillLevel" type="string">
              Proficiency level, for example `Beginner`, `Intermediate`, `Advanced`, or `Expert`.
            </ResponseField>
            <ResponseField name="requirementType" type="string">
              Whether the skill is `Compulsory` or `Optional`.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="scoring" type="object">
          Recruiter-defined Agent Interview scoring weights. Null on legacy jobs or when the recruiter has not customized the defaults; clients fall back to Technical 40 / Behavioral 25 / Logical 20 / Communication 15.
          <Expandable title="scoring properties">
            <ResponseField name="categories" type="array">
              Weighted scoring categories. Each `weight` is an integer percentage (1-100) and the weights across all categories sum to 100.
              <Expandable title="Category Object">
                <ResponseField name="name" type="string">
                  Category label.
                </ResponseField>
                <ResponseField name="weight" type="integer">
                  Integer percentage weight (1-100).
                </ResponseField>
              </Expandable>
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="createdAt" type="string">
          ISO 8601 timestamp of when the job was created.
        </ResponseField>
        <ResponseField name="updatedAt" type="string">
          ISO 8601 timestamp of the last update.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The caller lacks read access to jobs in this tenant |
| BAD_USER_INPUT | `id` is not a valid UUID |
| NOT_FOUND | No job with this `id` exists in the caller's tenant |
| INTERNAL_SERVER_ERROR | Unexpected server-side failure |
