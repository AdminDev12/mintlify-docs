---

## Overview

The `questionsByJob` query returns the questions in a job's Step-2 questionnaire, sorted by `order` — ordered rows first, then unordered rows by `createdAt`. Pass `parentCategory` to return only one interview round's questions (clients typically fire one query per round to segregate the list), or omit it to get every round in one flat list. To modify the questionnaire, use the `saveJobQuestionnaire`, `addJobQuestion`, `updateJobQuestion`, and `deleteJobQuestion` mutations.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query QuestionsByJob($jobId: UUID!, $parentCategory: String) {
  questionsByJob(jobId: $jobId, parentCategory: $parentCategory) {
    id
    jobId
    qId
    question
    sampleAnswer
    questionCategory
    parentCategory
    selected
    suggested
    order
    createdAt
    updatedAt
  }
}
```

## Request Parameters

<ParamField body="jobId" type="string" required>
  UUID of the job whose questions to retrieve. The job must belong to the caller's tenant.
</ParamField>

<ParamField body="parentCategory" type="string">
  Restrict results to one interview round. Matched exactly against the stored `parentCategory` — one of the `ParentCategory` enum values (`AI_Interview`, `Panel_Round`, `HR_Round`, `Calling_Agent`) or the per-stage name when the job has a pipeline. Omit to return every round in one flat list.
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="questionsByJob" type="array">
      The job's questions, sorted by `order` (ordered rows first, then unordered rows by `createdAt`).

      <Expandable title="Question Object">
        <ResponseField name="id" type="string">
          Unique question identifier (UUID).
        </ResponseField>
        <ResponseField name="jobId" type="string">
          Identifier of the job this question belongs to.
        </ResponseField>
        <ResponseField name="qId" type="string">
          Server-generated short question identifier.
        </ResponseField>
        <ResponseField name="question" type="string">
          The interview question text.
        </ResponseField>
        <ResponseField name="sampleAnswer" type="string">
          Model answer used to grade candidate responses.
        </ResponseField>
        <ResponseField name="questionCategory" type="string">
          Question category. One of the `QuestionCategory` enum values: `Technical`, `Behavioral`, `Logical`, `Communication`.
        </ResponseField>
        <ResponseField name="parentCategory" type="string">
          Interview round the question belongs to — one of the `ParentCategory` enum values (`AI_Interview`, `Panel_Round`, `HR_Round`, `Calling_Agent`) or the per-stage name when the job has a pipeline.
        </ResponseField>
        <ResponseField name="selected" type="boolean">
          Whether the question is selected for use in the interview.
        </ResponseField>
        <ResponseField name="suggested" type="boolean">
          Whether the question was suggested by the LLM rather than authored by the recruiter.
        </ResponseField>
        <ResponseField name="order" type="integer">
          Display position within the Step-2 questionnaire list; lower shows first. Null on rows created before ordering shipped.
        </ResponseField>
        <ResponseField name="createdAt" type="string">
          ISO 8601 timestamp of when the question was created.
        </ResponseField>
        <ResponseField name="updatedAt" type="string">
          ISO 8601 timestamp of the last update.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The caller lacks read access to jobs in this tenant |
| BAD_USER_INPUT | `jobId` is not a valid UUID |
| NOT_FOUND | No job with this `jobId` exists in the caller's tenant |
| INTERNAL_SERVER_ERROR | Unexpected server-side failure |
