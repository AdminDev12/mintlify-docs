## Overview

`cancelPanelRound` cancels a scheduled panel round. It deletes the calendar event on the organizer's calendar, and Outlook automatically sends cancellation notices to all attendees. Only rounds in `SCHEDULED` status are cancellable; the mutation returns the updated round record. Rounds are created with `schedulePanelRound` or in bulk with `sendPanelRoundInvites`.

<Note>
This operation requires the **write** scope.
</Note>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation CancelPanelRound($id: UUID!) {
  cancelPanelRound(id: $id) {
    id
    jobId
    candidateId
    status
    roundType
    captureMode
    scheduledAt
    durationMinutes
    correlationId
    updatedAt
  }
}
```

## Request Parameters

<ParamField body="id" type="string" required>
  UUID of the panel round to cancel. Only rounds in `SCHEDULED` status can be cancelled.
</ParamField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The credential lacks the write scope required to cancel rounds |
| BAD_USER_INPUT | Malformed UUID, or the round is not in `SCHEDULED` status and cannot be cancelled |
| NOT_FOUND | No panel round exists with the given ID |
| INTERNAL_SERVER_ERROR | Unexpected server error while deleting the calendar event |
