## Overview

`getPanelReport` fetches the AI-generated report for a panel session by session ID. The report contains the overall score, hiring recommendation, per-competency scores with transcript-backed evidence, red flags, key moments, and a narrative summary. Use `getPanelSession` to check the session's `pipelineStatus`; the report becomes available once processing reaches `COMPLETE`.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query GetPanelReport($sessionId: UUID!) {
  getPanelReport(sessionId: $sessionId) {
    id
    sessionId
    interviewSessionId
    reportVersion
    roundType
    overallScore
    recommendation
    summary
    redFlags
    competencyScores {
      competency
      weight
      score
      evidence
      transcriptReference {
        start_ms
        end_ms
      }
    }
    keyMoments {
      timestamp_ms
      label
      type
    }
    modelVersion
    generatedAt
  }
}
```

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="getPanelReport" type="object">
      The panel report, or `null` if no report exists for the session

      <Expandable title="getPanelReport properties">
        <ResponseField name="id" type="string">
          UUID of the report
        </ResponseField>

        <ResponseField name="sessionId" type="string">
          UUID of the panel session the report was generated from
        </ResponseField>

        <ResponseField name="interviewSessionId" type="string">
          UUID of the parent interview session
        </ResponseField>

        <ResponseField name="reportVersion" type="string">
          Version of this report document
        </ResponseField>

        <ResponseField name="roundType" type="string">
          Type of round the report covers: `PANEL` or `HR`
        </ResponseField>

        <ResponseField name="overallScore" type="number">
          Overall score for the round
        </ResponseField>

        <ResponseField name="recommendation" type="string">
          Hiring recommendation. One of `PROCEED`, `HOLD`, `REJECT`.
        </ResponseField>

        <ResponseField name="summary" type="string">
          Narrative summary of the candidate's performance
        </ResponseField>

        <ResponseField name="redFlags" type="array">
          Red flags surfaced during the round; empty when none were found
        </ResponseField>

        <ResponseField name="competencyScores" type="array">
          Per-competency scores

          <Expandable title="CompetencyScore object">
            <ResponseField name="competency" type="string">
              Name of the competency evaluated
            </ResponseField>

            <ResponseField name="weight" type="number">
              Relative weight of this competency; may be null
            </ResponseField>

            <ResponseField name="score" type="number">
              Score awarded for this competency
            </ResponseField>

            <ResponseField name="evidence" type="string">
              Evidence supporting the score
            </ResponseField>

            <ResponseField name="transcriptReference" type="object">
              Transcript span backing the evidence, with `start_ms` and `end_ms` millisecond offsets; may be null
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="keyMoments" type="array">
          Notable moments in the session

          <Expandable title="KeyMoment object">
            <ResponseField name="timestamp_ms" type="integer">
              Millisecond offset of the moment within the session
            </ResponseField>

            <ResponseField name="label" type="string">
              Short description of the moment
            </ResponseField>

            <ResponseField name="type" type="string">
              Moment classification. One of `POSITIVE`, `NEUTRAL`, `CONCERN`.
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="modelVersion" type="string">
          Version of the model that generated the report
        </ResponseField>

        <ResponseField name="generatedAt" type="string">
          When the report was generated (ISO 8601 DateTime)
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The credential is not permitted to read panel reports in this tenant |
| BAD_USER_INPUT | The `sessionId` value is not a valid UUID |
| NOT_FOUND | No report exists for the given session ID |
| INTERNAL_SERVER_ERROR | Unexpected server error while fetching the report |
