## Overview

`getPanelSession` fetches a panel session by ID, including the bot status, processing pipeline status, and recording signed URL. The `source` field tells you which capture flow produced the session: `TEAMS` sessions also populate `meetingId`, `graphEventId`, and `teamsJoinUrl`, while `VIDEOSDK` sessions populate `videoSdkRoomId`. Use `getPanelReport` to fetch the AI-generated report for a session, and `getRefreshedRecordingUrl` when the recording signed URL has expired.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query GetPanelSession($id: UUID!) {
  getPanelSession(id: $id) {
    id
    interviewSessionId
    source
    meetingId
    teamsJoinUrl
    videoSdkRoomId
    botStatus
    pipelineStatus
    roundType
    scheduledAt
    startedAt
    endedAt
    recordingSignedUrl
    recordingSignedUrlExpiry
    correlationId
    createdAt
    updatedAt
  }
}
```

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="getPanelSession" type="object">
      The panel session, or `null` if none matches the ID

      <Expandable title="getPanelSession properties">
        <ResponseField name="id" type="string">
          UUID of the panel session
        </ResponseField>

        <ResponseField name="interviewSessionId" type="string">
          UUID of the parent interview session
        </ResponseField>

        <ResponseField name="source" type="string">
          Which capture flow produced this session: `TEAMS` or `VIDEOSDK`. `TEAMS` sessions also populate `meetingId`, `graphEventId`, and `teamsJoinUrl`; `VIDEOSDK` sessions populate `videoSdkRoomId`. Defaults to `TEAMS` for sessions written before the field was introduced.

        <ResponseField name="meetingId" type="string">
          Teams meeting ID. Null for `VIDEOSDK` sessions.
        </ResponseField>

        <ResponseField name="teamsJoinUrl" type="string">

        </ResponseField>

        <ResponseField name="videoSdkRoomId" type="string">
          videosdk.live room ID. Null for `TEAMS` sessions.
        </ResponseField>

        <ResponseField name="botStatus" type="string">
          Capture bot status. One of `PENDING`, `JOINED`, `ACTIVE`, `RECORDING`, `ENDED`.
        </ResponseField>

        <ResponseField name="pipelineStatus" type="string">
          Post-session processing pipeline status. One of `PENDING`, `IN_PROGRESS`, `COMPLETE`, `FAILED`.
        </ResponseField>

        <ResponseField name="roundType" type="string">
          Type of round: `PANEL` or `HR`

        <ResponseField name="startedAt" type="string">

        <ResponseField name="recordingSignedUrl" type="string">

        </ResponseField>

        <ResponseField name="recordingSignedUrlExpiry" type="string">
          Expiry timestamp of the signed URL (ISO 8601 DateTime). Use `getRefreshedRecordingUrl` after it expires.
        </ResponseField>

        <ResponseField name="correlationId" type="string">
          Correlation ID for tracing this session across services
        </ResponseField>

        <ResponseField name="createdAt" type="string">
          Creation timestamp (ISO 8601 DateTime)
        </ResponseField>

        <ResponseField name="updatedAt" type="string">
          Last update timestamp (ISO 8601 DateTime)
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The credential is not permitted to read panel sessions in this tenant |
| BAD_USER_INPUT | The `id` value is not a valid UUID |
| NOT_FOUND | No panel session exists with the given ID |
| INTERNAL_SERVER_ERROR | Unexpected server error while fetching the session |
