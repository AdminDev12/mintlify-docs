## Overview

`schedulePanelRound` schedules a panel or HR interview round for one candidate. It creates a Teams meeting on the calling recruiter's calendar (Outlook invites are sent automatically to all attendees) and publishes a `panel.session.scheduled` event so the Exterview bot can dial in two minutes before the start time. Use this operation for one-off, per-candidate scheduling; to dispatch invites to a batch of candidates in a single call, use `sendPanelRoundInvites` instead.

<Note>
This operation requires the **write** scope.
</Note>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation SchedulePanelRound($input: SchedulePanelRoundInput!) {
  schedulePanelRound(input: $input) {
    id
    jobId
    candidateId
    status
    roundType
    captureMode
    recruiterUserIds
    organizerUserOid
    teamsJoinUrl
    scheduledAt
    durationMinutes
    correlationId
    createdAt
  }
}
```

## Request Parameters

<ParamField body="jobId" type="string" required>
  UUID of the job the round belongs to
</ParamField>

<ParamField body="candidateId" type="string" required>
  UUID of the candidate being interviewed
</ParamField>

<ParamField body="recruiterUserIds" type="array" required>
  AAD object IDs of the recruiters that should be on the call. The calling recruiter is added automatically as the organizer.
</ParamField>

<ParamField body="scheduledAt" type="string" required>
  When the round begins (ISO 8601 DateTime)
</ParamField>

<ParamField body="durationMinutes" type="integer" default={45}>
  Meeting length in minutes. Defaults to 45 when omitted.
</ParamField>

<ParamField body="roundType" type="RoundType" required>
  Type of round. Allowed values: `PANEL`, `HR`
</ParamField>

<ParamField body="subjectOverride" type="string">
  Custom subject line for the calendar invite
</ParamField>

<ParamField body="timeZone" type="string" default="UTC">
  IANA time zone (for example, `Asia/Kolkata`). Defaults to UTC.
</ParamField>

<ParamField body="captureMode" type="PanelCaptureMode" default="TEAMS">
  Capture flow. `TEAMS` dials an Exterview bot into a Teams meeting (requires Bot Framework admin consent on the tenant); `VIDEOSDK` provisions a native Exterview videosdk.live room. Defaults to `TEAMS`.
</ParamField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The credential lacks the write scope required to schedule rounds |
| BAD_USER_INPUT | Invalid input, such as a malformed UUID, an unknown IANA time zone, or an invalid `scheduledAt` value |
| NOT_FOUND | The specified job or candidate does not exist |
| INTERNAL_SERVER_ERROR | Unexpected server error while creating the meeting or publishing the scheduled event |
