## Overview

`sendPanelRoundInvites` dispatches panel or HR round invites to a batch of candidates on a job in one call. The job's pipeline must contain a `PANEL_INTERVIEW_*` or `HR_ROUND_*` stage; that stage's metadata supplies the panelist user IDs, default duration, and capture mode, so the call site only needs to provide the per-batch `scheduledAt`. It mirrors the shape of `sendCodingAssessmentInvites` and `sendAiInterviewInvites`, and is restricted to the Admin and Recruiter roles. For one-off, per-candidate scheduling, use `schedulePanelRound` instead.

<Warning>
This operation requires the billing/comms-impacting scope because it sends real communications to candidates and incurs usage costs.
</Warning>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation SendPanelRoundInvites($input: SendPanelRoundInvitesInput!) {
  sendPanelRoundInvites(input: $input) {
    total
    sent
    failed
    failedCandidateIds
  }
}
```

## Request Parameters

<ParamField body="jobId" type="string" required>
  ID of the job whose pipeline contains the panel or HR round stage
</ParamField>

<ParamField body="candidateIds" type="array" required>
  IDs of the candidates to invite in this batch
</ParamField>

<ParamField body="scheduledAt" type="string" required>
  When the round begins (ISO 8601 DateTime). A single value applies across the whole batch, matching the recruiter UI's "send to selected, scheduled at" flow. For one-off per-candidate scheduling, use `schedulePanelRound` instead.
</ParamField>

<ParamField body="durationMinutes" type="integer">
  Override the duration baked into `stage.metadata.durationMinutes` for this batch. Optional; falls back to stage metadata, then 45.
</ParamField>

<ParamField body="captureMode" type="PanelCaptureMode">
  Override the capture flow for this batch. Allowed values: `TEAMS` (Microsoft Teams bot; Marketplace and Entra-consented tenants only) or `VIDEOSDK` (native Exterview videosdk.live room). Optional; falls back to `stage.metadata.captureMode`, then `TEAMS`.
</ParamField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The caller is not an Admin or Recruiter, or the credential lacks the billing/comms-impacting scope |
| BAD_USER_INPUT | Invalid input, such as an empty `candidateIds` list, an invalid `scheduledAt` value, or a job whose pipeline has no `PANEL_INTERVIEW_*` or `HR_ROUND_*` stage |
| NOT_FOUND | The specified job does not exist |
| INTERNAL_SERVER_ERROR | Unexpected server error while dispatching the batch |
