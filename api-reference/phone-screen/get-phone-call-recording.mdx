## Overview

Retrieve a focused recording projection for one AI phone screen call. The same data is also available as fields of `phoneCallRecord`, but recruiter and audit-replay consumers that only need the media URL benefit from this lighter shape and a distinct operation name in cache keys and traces. The `available` flag flips to `true` once the post-call webhook has copied the recording from the provider into Exterview blob storage; until then `recordingUrl` is `null` and the consumer should poll.

<Note>
  The response contains a short-lived media URL that exposes candidate PII (the candidate's voice and screening conversation). Access to this operation is gated behind a data-access scope.
</Note>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query GetPhoneCallRecording($phoneCallId: UUID!) {
  phoneCallRecording(phoneCallId: $phoneCallId) {
    phoneCallId
    status
    recordingUrl
    durationSeconds
    available
  }
}
```

## Request Parameters

<ParamField body="phoneCallId" type="string" required>
  UUID of the phone call whose recording should be returned. The operation returns `null` for an unknown ID or an ID belonging to another tenant (no existence oracle). While the call is still in progress or the post-call webhook has not fired yet, the row is returned with `available: false` and `recordingUrl: null`.
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="phoneCallRecording" type="object">
      The recording projection, or `null` when the ID is unknown or belongs to another tenant.

      <Expandable title="phoneCallRecording properties">
        <ResponseField name="phoneCallId" type="string">
          UUID of the phone call this recording belongs to
        </ResponseField>

        <ResponseField name="status" type="string">
          Call status. Enum `PhoneCallStatus`: `INITIATING`, `IN_PROGRESS`, `COMPLETED`, `FAILED`, `NO_ANSWER`, `BUSY`, `CANCELLED`
        </ResponseField>

        <ResponseField name="recordingUrl" type="string">
          Short-lived URL of the call recording. `null` until the post-call webhook has copied the recording into blob storage
        </ResponseField>

        <ResponseField name="durationSeconds" type="integer">
          Recording duration in seconds
        </ResponseField>

        <ResponseField name="available" type="boolean">
          `true` once the recording has been copied from the provider to Exterview blob storage and `recordingUrl` is populated
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

| Error Code | Description |
| --- | --- |
| `UNAUTHENTICATED` | Missing or invalid API key or bearer token |
| `FORBIDDEN` | The authenticated principal lacks the Admin or Recruiter role, or the required data-access scope |
| `BAD_USER_INPUT` | The `phoneCallId` argument is not a valid UUID |
| `INTERNAL_SERVER_ERROR` | Unexpected server-side failure |
