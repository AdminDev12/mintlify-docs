## Overview

Retrieve a focused transcript projection for one AI phone screen call. The same data is also available as fields of `phoneCallRecord`, but consumers that only need the transcript benefit from this lighter shape and a distinct operation name in cache keys and traces. Either `transcriptUrl` or `transcriptText` may be populated (or both — they carry the same content in different forms), and `hasContent` is `true` when either is present.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query GetPhoneCallTranscript($phoneCallId: UUID!) {
  phoneCallTranscript(phoneCallId: $phoneCallId) {
    phoneCallId
    status
    transcriptUrl
    transcriptText
    hasContent
  }
}
```

## Request Parameters

<ParamField body="phoneCallId" type="string" required>
  UUID of the phone call whose transcript should be returned. The operation returns `null` for an unknown ID or an ID belonging to another tenant (no existence oracle). While the call is still in progress or post-call processing has not finished, the row is returned with `hasContent: false`.
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="phoneCallTranscript" type="object">
      The transcript projection, or `null` when the ID is unknown or belongs to another tenant.

      <Expandable title="phoneCallTranscript properties">
        <ResponseField name="phoneCallId" type="string">
          UUID of the phone call this transcript belongs to
        </ResponseField>

        <ResponseField name="status" type="string">
          Call status. Enum `PhoneCallStatus`: `INITIATING`, `IN_PROGRESS`, `COMPLETED`, `FAILED`, `NO_ANSWER`, `BUSY`, `CANCELLED`
        </ResponseField>

        <ResponseField name="transcriptUrl" type="string">
          URL of the transcript file, when available
        </ResponseField>

        <ResponseField name="transcriptText" type="string">
          Inline transcript text, when available. Carries the same content as `transcriptUrl` in a different form
        </ResponseField>

        <ResponseField name="hasContent" type="boolean">
          `true` when either `transcriptUrl` or `transcriptText` is present
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

| Error Code | Description |
| --- | --- |
| `UNAUTHENTICATED` | Missing or invalid API key or bearer token |
| `FORBIDDEN` | The authenticated principal lacks the Admin or Recruiter role |
| `BAD_USER_INPUT` | The `phoneCallId` argument is not a valid UUID |
| `INTERNAL_SERVER_ERROR` | Unexpected server-side failure |
