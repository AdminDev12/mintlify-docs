## Overview

Queue outbound AI phone screen calls for a batch of candidates in a single request. The operation accepts a list of candidate identifiers plus optional per-candidate phone and email overrides, and returns a summary with the identifiers of the phone call records it created. To dial a single candidate, use `initiatePhoneCall`; to stop an individual call from the batch, use `cancelPhoneCall`.

<Warning>
This operation requires the billing/comms-impacting scope because it sends real communications to candidates and incurs usage costs. Each candidate in the batch receives a live outbound phone call.
</Warning>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation InitiateBulkPhoneCalls($input: InitiateBulkPhoneCallsInput!) {
  initiateBulkPhoneCalls(input: $input) {
    total
    status
    phoneCallIds
  }
}
```

## Request Parameters

<ParamField body="candidateIds" type="array" required>
  List of candidate identifiers to call. Each candidate's phone number on file is dialed unless an override is supplied for that candidate in `overrides`.
</ParamField>

<ParamField body="overrides" type="array">
  Optional list of per-candidate contact overrides. Each entry applies to the candidate whose `candidateId` it names.

  <Expandable title="Override object">
    <ParamField body="candidateId" type="string" required>
      Identifier of the candidate this override applies to. Must also appear in `candidateIds`.
    </ParamField>

    <ParamField body="phone" type="string">
      Phone number to dial instead of the number stored on the candidate record. Use E.164 format (for example `+14155550123`).
    </ParamField>

    <ParamField body="email" type="string">
      Email address to use instead of the address stored on the candidate record.
    </ParamField>
  </Expandable>
</ParamField>

## Error Responses

| Error Code | Description |
| --- | --- |
| `UNAUTHENTICATED` | Missing or invalid API key or bearer token. |
| `FORBIDDEN` | The caller lacks the Admin or Recruiter role, or lacks the billing/comms-impacting scope. |
| `BAD_USER_INPUT` | Invalid input, such as an empty `candidateIds` list or an override referencing a candidate not in the batch. |
| `NOT_FOUND` | One or more supplied candidate identifiers do not exist. |
| `INTERNAL_SERVER_ERROR` | The telephony provider could not be reached or an unexpected server error occurred. |
