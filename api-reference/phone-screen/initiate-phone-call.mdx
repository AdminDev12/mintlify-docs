## Overview

Initiate an outbound AI phone screen call to one candidate. The platform selects a telephony provider (`EXOTEL` or `ELEVENLABS_TWILIO`), dials the candidate's number, and returns the newly created phone call record along with the provider-side identifiers you can use to track the call. To dial many candidates in one request, use `initiateBulkPhoneCalls` instead; to stop a call you started, use `cancelPhoneCall`.

<Warning>
This operation requires the billing/comms-impacting scope because it sends real communications to candidates and incurs usage costs. A successful call places a live outbound phone call to the candidate's number.
</Warning>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation InitiatePhoneCall($input: InitiatePhoneCallInput!) {
  initiatePhoneCall(input: $input) {
    provider
    conversationId
    callSid
    phoneCall {
      id
      candidateId
      jobId
      organizationId
      provider
      toNumber
      status
      createdAt
    }
  }
}
```

## Request Parameters

<ParamField body="candidateId" type="string" required>
  Identifier of the candidate to call. The candidate's phone number on file is dialed unless `overridePhone` is provided.
</ParamField>

<ParamField body="overridePhone" type="string">
  Optional phone number to dial instead of the number stored on the candidate record. Use E.164 format (for example `+14155550123`).
</ParamField>

    <ResponseField name="initiatePhoneCall" type="object">

            <ResponseField name="id" type="string">

            <ResponseField name="candidateId" type="string">

            </ResponseField>

            <ResponseField name="jobId" type="string">
              Identifier of the job the phone screen belongs to.

            <ResponseField name="organizationId" type="string">
              Identifier of the organization that owns the call.

          </Expandable>

      </Expandable>

## Error Responses

| Error Code | Description |
| --- | --- |
| `UNAUTHENTICATED` | Missing or invalid API key or bearer token. |
| `FORBIDDEN` | The caller lacks the Admin or Recruiter role, or lacks the billing/comms-impacting scope. |
| `BAD_USER_INPUT` | Invalid input, such as a malformed `overridePhone` or a candidate with no phone number to dial. |
| `NOT_FOUND` | No candidate exists for the supplied `candidateId`. |
| `INTERNAL_SERVER_ERROR` | The telephony provider could not be reached or an unexpected server error occurred. |
