## Overview

Retrieve every AI phone screen call record associated with a job, across all candidates. Use this operation to build a job-level view of screening activity — how many calls completed, failed, or went unanswered — and to collect call IDs for follow-up lookups. To scope results to a single candidate instead, use `phoneCallsByCandidate`; to fetch one call in full detail, use `phoneCallRecord`.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query PhoneCallsByJob($jobId: String!) {
  phoneCallsByJob(jobId: $jobId) {
    id
    candidateId
    jobId
    organizationId
    provider
    toNumber
    status
    startedAt
    endedAt
    totalDurationSeconds
    formattedDuration
    failureReason
    analysisStatus
    createdAt
  }
}
```

## Request Parameters

<ParamField body="jobId" type="string" required>
  Identifier of the job whose phone call records should be returned. An empty array is returned when the job has no calls.
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="phoneCallsByJob" type="array">
      Array of phone call records for the job

      <Expandable title="Phone Call Record Object">
        <ResponseField name="id" type="string">
          Unique identifier (UUID) of the phone call record
        </ResponseField>

        <ResponseField name="candidateId" type="string">
          Identifier of the candidate who was called
        </ResponseField>

        <ResponseField name="jobId" type="string">
          Identifier of the job the call was screened for
        </ResponseField>

        <ResponseField name="organizationId" type="string">
          Identifier of the organization
        </ResponseField>

        <ResponseField name="provider" type="string">
          Telephony provider used for the call. Enum `PhoneCallProvider`: `EXOTEL`, `ELEVENLABS_TWILIO`
        </ResponseField>

        <ResponseField name="toNumber" type="string">
          Phone number that was dialed
        </ResponseField>

        <ResponseField name="status" type="string">
          Call status. Enum `PhoneCallStatus`: `INITIATING`, `IN_PROGRESS`, `COMPLETED`, `FAILED`, `NO_ANSWER`, `BUSY`, `CANCELLED`
        </ResponseField>

        <ResponseField name="startedAt" type="string">
          ISO 8601 timestamp when the call started, or `null` if it has not started
        </ResponseField>

        <ResponseField name="endedAt" type="string">
          ISO 8601 timestamp when the call ended, or `null` if it has not ended
        </ResponseField>

        <ResponseField name="totalDurationSeconds" type="integer">
          Total call duration in seconds
        </ResponseField>

        <ResponseField name="formattedDuration" type="string">
          Human-readable call duration
        </ResponseField>

        <ResponseField name="failureReason" type="string">
          Reason the call failed or was cancelled, when applicable
        </ResponseField>

        <ResponseField name="analysisStatus" type="string">
          Status of the AI post-call analysis
        </ResponseField>

        <ResponseField name="createdAt" type="string">
          ISO 8601 timestamp when the record was created
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>
