---

## Overview

Returns where each supplied candidate currently stands on every stage of a job's pipeline, as a per-candidate, per-stage status matrix. For each stage it projects the relevant invite or round record onto a unified status enum, so clients can render one status cell per candidate and stage and decide which follow-up action to take. Results come back one entry per supplied candidate (preserving input order), each with one `rounds` entry per pipeline stage in ascending order; the query returns `[]` when the job has no pipeline attached.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query candidateRoundStatuses($jobId: UUID!, $candidateIds: [UUID!]!) {
  candidateRoundStatuses(jobId: $jobId, candidateIds: $candidateIds) {
    candidateId
    rounds {
      stageId
      stageName
      stageType
      stageOrder
      status
      scheduledAt
      completedAt
    }
  }
}
```

## Request Parameters

<ParamField body="jobId" type="string" required>
  UUID of the job. Must belong to the caller's tenant; the job's pipeline is used to discover the stage list.
</ParamField>

<ParamField body="candidateIds" type="array" required>
  Array of candidate UUIDs (1 to 500 entries, must be non-empty). Candidates that do not belong to this job or tenant are silently dropped from the result.
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="candidateRoundStatuses" type="array">
      One entry per supplied candidate, in input order. Empty when the job has no pipeline attached.

      <Expandable title="CandidateRoundStatusSet Object">
        <ResponseField name="candidateId" type="string">
          Candidate identifier (UUID)
        </ResponseField>

        <ResponseField name="rounds" type="array">
          One entry per pipeline stage, in ascending pipeline order, so clients can render columns without re-sorting

          <Expandable title="Round Object">
            <ResponseField name="stageId" type="string">
              Pipeline stage id (UUID), stable across recruiters
            </ResponseField>

            <ResponseField name="stageName" type="string">
              Stage display name, for example "Phone Screen"
            </ResponseField>

            <ResponseField name="stageType" type="string">
              Stage type from the pipeline, for example PHONE_AGENT or AUDIO_INTERVIEW
            </ResponseField>

            <ResponseField name="stageOrder" type="integer">
              1-indexed pipeline order; clients label columns R1, R2, and so on using this
            </ResponseField>

            <ResponseField name="status" type="string">
              Normalized lifecycle for this candidate on this stage. One of `NOT_SENT` (no invite yet), `SCHEDULED` (invite created, round not begun), `STARTED` (round began), `COMPLETED` (round finished and analysis done), `CANCELLED` (cancelled before it began), `EXPIRED` (candidate did not act within the deadline), `FAILED` (round began but failed to complete), `NOT_APPLICABLE` (stage is not candidate-actionable, e.g. resume screening)
            </ResponseField>

            <ResponseField name="scheduledAt" type="string">
              When the round is scheduled to begin (ISO 8601). `null` when status is `NOT_SENT` or `NOT_APPLICABLE`
            </ResponseField>

            <ResponseField name="completedAt" type="string">
              When the round actually completed (ISO 8601). `null` until `COMPLETED` or `FAILED`
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

| Error Code | Description |
| --- | --- |
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The caller lacks access to this tenant's data |
| BAD_USER_INPUT | `candidateIds` is empty or exceeds 500 entries, or an id is not a valid UUID |
| NOT_FOUND | The job does not exist in the caller's tenant |
| INTERNAL_SERVER_ERROR | Unexpected server error while composing the status matrix |
