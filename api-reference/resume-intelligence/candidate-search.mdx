## Overview

Runs a free-text recruiter query (for example, "senior backend engineers who've worked in fintech and led a team") over the whole organization's candidate pool. The query is embedded, the nearest candidates are retrieved by metadata-vector similarity, and a chat model ranks and explains them grounded only in the retrieved profiles, returning a narrative `answer` plus a ranked, explained shortlist. When the embeddings deployment is not yet provisioned, retrieval cannot run and the result comes back with `enabled: false`; for structured, per-job listing use `candidatesByJob` or `candidates` instead.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query candidateSearch($query: String!, $limit: Int) {
  candidateSearch(query: $query, limit: $limit) {
    enabled
    answer
    results {
      similarity
      rationale
      candidate {
        id
        name
        email
        role
        candidateCompany
        experience
        skillsFound
        resumeScore
      }
    }
  }
}
```

## Request Parameters

<ParamField body="query" type="string" required>
  Free-text search query describing the candidates you are looking for.
</ParamField>

<ParamField body="limit" type="integer" default={10}>
  Maximum number of ranked hits to return.
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="candidateSearch" type="object">
      Result envelope for the retrieval-plus-generation search.

      <Expandable title="candidateSearch properties">
        <ResponseField name="enabled" type="boolean">
          False until the embeddings deployment is provisioned; when false, search is unavailable and `answer` is empty
        </ResponseField>

        <ResponseField name="answer" type="string">
          Narrative summary of who stands out and why (empty when disabled)
        </ResponseField>

        <ResponseField name="results" type="array">
          Ranked, explained shortlist of matching candidates

          <Expandable title="Search Hit Object">
            <ResponseField name="similarity" type="number">
              Cosine similarity of the candidate's metadata vector to the query, from 0 to 1
            </ResponseField>

            <ResponseField name="rationale" type="string">
              One- to two-sentence reason this candidate fits, grounded in their profile
            </ResponseField>

            <ResponseField name="candidate" type="object">
              The matched candidate

              <Expandable title="Candidate Object">
                <ResponseField name="id" type="string">
                  Unique candidate identifier (UUID)
                </ResponseField>

                <ResponseField name="name" type="string">
                  Candidate's full name
                </ResponseField>

                <ResponseField name="email" type="string">
                  Candidate's email address (nullable)
                </ResponseField>

                <ResponseField name="role" type="string">
                  Candidate's current or most recent role (nullable)
                </ResponseField>

                <ResponseField name="candidateCompany" type="string">
                  Candidate's current company (nullable)
                </ResponseField>

                <ResponseField name="experience" type="string">
                  Free-form work-experience summary (nullable)
                </ResponseField>

                <ResponseField name="skillsFound" type="array">
                  Skills extracted from the resume
                </ResponseField>

                <ResponseField name="resumeScore" type="number">
                  Aggregate resume score (nullable)
                </ResponseField>
              </Expandable>
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>

## Error Responses

| Error Code | Description |
| --- | --- |
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | The caller lacks access to this tenant's candidate data |
| BAD_USER_INPUT | `query` is empty or `limit` is not a positive integer |
| INTERNAL_SERVER_ERROR | Embedding, retrieval, or ranking failed unexpectedly |
