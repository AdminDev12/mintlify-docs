## Overview

`jobLeaderboard` returns the ranked candidates for a single job, with a composite `score` computed in one of three modes. Supply `stage` to rank by one stage's score alone, supply `weights` to rank by a weighted sum normalized over stages that currently have data, or supply neither for an equal-weight average over stages with data. Supplying both `stage` and `weights` is rejected as invalid input. Use `jobStackRank` instead when you only need the resume-score ordering.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query JobLeaderboard($jobId: UUID!, $weights: [StageWeightInput!], $limit: Int, $offset: Int) {
  jobLeaderboard(jobId: $jobId, weights: $weights, limit: $limit, offset: $offset) {
    id
    name
    rank
    score
    stageScores {
      stage
      score
    }
  }
}
```

## Request Parameters

<ParamField body="jobId" type="string" required>
  UUID of the job to rank candidates for
</ParamField>

<ParamField body="stage" type="LeaderboardStage">
  Rank by this stage's score alone; candidates with no score for the stage sort last with a null score. One of `AI_SCREENING`, `PHONE`, `AVATAR_INTERVIEW`, `PANEL`, `HR`. Cannot be combined with `weights`
</ParamField>

<ParamField body="weights" type="array">
  Per-stage weights for composite scoring. The composite is the weighted sum of stage scores, normalized over stages that currently have data, so a missing stage does not penalize a candidate by contributing 0. Across a single request, weights must be strictly positive, sum to 1.0 (plus or minus 0.01), and reference each stage at most once. Cannot be combined with `stage`

  <Expandable title="StageWeightInput fields">
    <ParamField body="stage" type="LeaderboardStage" required>
      Stage the weight applies to. One of `AI_SCREENING`, `PHONE`, `AVATAR_INTERVIEW`, `PANEL`, `HR`
    </ParamField>

    <ParamField body="weight" type="number" required>
      Weight to assign to the stage when computing the composite score
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="limit" type="integer" default={50}>
  Maximum number of entries to return; capped server-side at 500
</ParamField>

<ParamField body="offset" type="integer" default={0}>
  Zero-based offset into the ranked list
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="jobLeaderboard" type="array">
      Ranked leaderboard entries, one per candidate

      <Expandable title="LeaderboardEntry Object">
        <ResponseField name="id" type="string">
          UUID of the candidate

        <ResponseField name="name" type="string">
          Candidate's full name

        <ResponseField name="rank" type="integer">
          Position of the candidate in the ranking

            </ResponseField>

            <ResponseField name="score" type="number">
              Score for the stage; null when no data exists for that stage, for example a phone call not yet completed
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| `UNAUTHENTICATED` | Missing or invalid API key or bearer token |
| `FORBIDDEN` | The caller is not permitted to read this job's leaderboard |
| `BAD_USER_INPUT` | Both `stage` and `weights` supplied, or weights are non-positive, repeat a stage, or do not sum to 1.0 (plus or minus 0.01) |
| `INTERNAL_SERVER_ERROR` | Unexpected server-side failure while computing the leaderboard |
