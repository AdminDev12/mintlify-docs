## Overview

`jobStackRank` is the canonical stack-rank read for a single job. It returns the same data as `candidatesByJob` with `sortBy: RESUME_SCORE` and `sortDir: DESC`, exposed as a named query so the recruiter UI and the leaderboard feature can share one resolver and one cache key. The result is paged because at scale a single job can hold thousands of candidates; candidates without a `resumeScore` sort after scored ones, so partially scored pools surface scored rows first.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query JobStackRank($jobId: UUID!, $perPage: Int, $pageNumber: Int) {
  jobStackRank(jobId: $jobId, perPage: $perPage, pageNumber: $pageNumber) {
    items {
      id
      name
      email
      role
      resumeScore
      aiInterviewStatus
      candidateStatus
      eligibility
      source
      isStarred
      organizationId
      createdAt
    }
  }
}
```

## Error Responses

| Error Code | Description |
|------------|-------------|
| `UNAUTHENTICATED` | Missing or invalid API key or bearer token |
| `FORBIDDEN` | The caller is not permitted to read candidates for this tenant |
| `BAD_USER_INPUT` | `jobId` is not a valid UUID or pagination arguments are malformed |
| `INTERNAL_SERVER_ERROR` | Unexpected server-side failure while ranking candidates |
