## Overview

Retrieve a paged audit trail of every override applied to a job's AI decisions, projected from the audit log for the target job. Events are sorted most recent first (`at DESC`), and each entry captures the full before and after state of the override, so you can reconstruct exactly who changed which verdict and when. Use this alongside `leaderboardRoundDecisions` and `leaderboardCandidateDecisions` when you need the change history rather than the current verdicts.

Access is restricted to Recruiter and Admin roles; Hiring Manager calls return `FORBIDDEN`.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query LeaderboardAuditTrail($input: LeaderboardAuditTrailInput!) {
  leaderboardAuditTrail(input: $input) {
    id
    decisionId
    jobId
    candidateId
    round
    actorId
    before
    after
    at
  }
}
```

## Request Parameters

<ParamField body="jobId" type="string" required>
  UUID of the job whose override audit trail to read
</ParamField>

<ParamField body="perPage" type="integer">
  Number of audit events to return per page
</ParamField>

<ParamField body="pageNumber" type="integer">
  Page number to fetch
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="leaderboardAuditTrail" type="array">
      Array of audit-trail events, sorted most recent first

      <Expandable title="AiDecisionOverrideAuditEvent">
        <ResponseField name="id" type="string">
          Unique identifier of the audit event
        </ResponseField>

        <ResponseField name="decisionId" type="string">
          Identifier of the AI decision row that was overridden
        </ResponseField>

        <ResponseField name="jobId" type="string">
          UUID of the job the decision belongs to
        </ResponseField>

        <ResponseField name="candidateId" type="string">
          UUID of the candidate the decision applies to
        </ResponseField>

        <ResponseField name="round" type="string">
          Interview round the overridden decision covers. One of `RESUME`, `PHONE`, `VOICE`, `AVATAR`. Null for candidate-level (across-rounds) decisions
        </ResponseField>

        <ResponseField name="actorId" type="string">
          Identifier of the user who applied the override
        </ResponseField>

        <ResponseField name="before" type="object">
          JSON snapshot of the decision's override state before the change
        </ResponseField>

        <ResponseField name="after" type="object">
          JSON snapshot of the decision's override state after the change
        </ResponseField>

        <ResponseField name="at" type="string">
          ISO 8601 timestamp of when the override was applied
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | Caller is a Hiring Manager; the audit trail is limited to Recruiter and Admin roles |
| BAD_USER_INPUT | `jobId` is not a valid UUID or pagination values are invalid |
| INTERNAL_SERVER_ERROR | Unexpected server-side failure while reading the audit log |
