## Overview

`leaderboardCandidateDecisions` lists the candidate-level AI verdicts for a job: one row per candidate, aggregated across rounds. Each row carries the AI's verdict, score, and reasoning plus any recruiter override, with `effectiveVerdict` as the derived field that resolves the override's verdict when present and the AI verdict otherwise. Use `leaderboardRoundDecisions` when you need the per-round breakdown instead of the one-row-per-candidate summary.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query LeaderboardCandidateDecisions($jobId: UUID!) {
  leaderboardCandidateDecisions(jobId: $jobId) {
    decisionId
    candidateId
    candidateName
    jobId
    aiVerdict
    aiScore
    aiReasoning
    aiProducedAt
    effectiveVerdict
    override {
      verdict
      reason
      byUserId
      at
    }
  }
}
```

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="leaderboardCandidateDecisions" type="array">
      Candidate-level AI verdict rows, one per candidate for the job

      <Expandable title="AiCandidateDecision Object">
        <ResponseField name="decisionId" type="string">
          Identifier of the decision row
        </ResponseField>

        <ResponseField name="candidateId" type="string">
          UUID of the candidate the decision belongs to
        </ResponseField>

        <ResponseField name="candidateName" type="string">
          Candidate's name, joined from the candidates container at resolver time
        </ResponseField>

        <ResponseField name="jobId" type="string">
          UUID of the job the decision belongs to
        </ResponseField>

        <ResponseField name="aiVerdict" type="string">
          Verdict produced by the AI across rounds. One of `ADVANCE`, `HOLD`, `REJECT`
        </ResponseField>

        <ResponseField name="aiScore" type="integer">
          Score the AI assigned to the candidate
        </ResponseField>

        <ResponseField name="aiReasoning" type="string">
          The AI's explanation for its verdict
        </ResponseField>

        <ResponseField name="aiProducedAt" type="string">
          ISO 8601 timestamp when the AI produced the verdict
        </ResponseField>

        <ResponseField name="effectiveVerdict" type="string">
          Derived verdict that resolves the override's verdict when present, otherwise the AI verdict. One of `ADVANCE`, `HOLD`, `REJECT`
        </ResponseField>

        <ResponseField name="override" type="object">
          Recruiter override block; null when the AI verdict has not been overridden

          <Expandable title="AiDecisionOverride Object">
            <ResponseField name="verdict" type="string">
              Overriding verdict. One of `ADVANCE`, `HOLD`, `REJECT`
            </ResponseField>

            <ResponseField name="reason" type="string">
              Reason the recruiter recorded for the override
            </ResponseField>

            <ResponseField name="byUserId" type="string">
              Identifier of the user who applied the override
            </ResponseField>

            <ResponseField name="at" type="string">
              ISO 8601 timestamp when the override was applied
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| `UNAUTHENTICATED` | Missing or invalid API key or bearer token |
| `FORBIDDEN` | The caller is not permitted to read decisions for this tenant |
| `BAD_USER_INPUT` | `jobId` is not a valid UUID |
| `INTERNAL_SERVER_ERROR` | Unexpected server-side failure while reading decisions |
