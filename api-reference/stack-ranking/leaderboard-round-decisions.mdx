## Overview

`leaderboardRoundDecisions` lists the per-round AI verdicts recorded for a job, sorted by candidate name and then round order (`RESUME`, `PHONE`, `VOICE`, `AVATAR`) at the resolver layer. Each row carries the AI's verdict, score, and reasoning plus any recruiter override, with `effectiveVerdict` resolving the override over the AI verdict. Use `leaderboardCandidateDecisions` for the one-row-per-candidate, across-rounds view. An unknown or cross-tenant `jobId` returns an empty list rather than an error, so there is no existence oracle across tenants.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query LeaderboardRoundDecisions($input: LeaderboardRoundDecisionsFilterInput!) {
  leaderboardRoundDecisions(input: $input) {
    decisionId
    candidateId
    candidateName
    jobId
    round
    aiVerdict
    aiScore
    aiReasoning
    aiProducedAt
    effectiveVerdict
    override {
      verdict
      reason
      byUserId
      at
    }
  }
}
```

## Request Parameters

<ParamField body="jobId" type="string" required>
  UUID of the job whose round decisions to list
</ParamField>

<ParamField body="round" type="AiDecisionRound">
  Filter to a single round. One of `RESUME`, `PHONE`, `VOICE`, `AVATAR`
</ParamField>

<ParamField body="verdict" type="AiDecisionVerdict">
  Filter to rows with this AI verdict. One of `ADVANCE`, `HOLD`, `REJECT`
</ParamField>

<ParamField body="overriddenOnly" type="boolean">
  When true, return only rows that carry a recruiter override
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="leaderboardRoundDecisions" type="array">
      Per-round AI verdict rows for the job

      <Expandable title="AiRoundDecision Object">
        <ResponseField name="decisionId" type="string">
          Identifier of the decision row
        </ResponseField>

        <ResponseField name="candidateId" type="string">
          UUID of the candidate the decision belongs to
        </ResponseField>

        <ResponseField name="candidateName" type="string">
          Candidate's name, joined from the candidates container at resolver time
        </ResponseField>

        <ResponseField name="jobId" type="string">
          UUID of the job the decision belongs to
        </ResponseField>

        <ResponseField name="round" type="string">
          Round the verdict applies to. One of `RESUME`, `PHONE`, `VOICE`, `AVATAR`
        </ResponseField>

        <ResponseField name="aiVerdict" type="string">
          Verdict produced by the AI. One of `ADVANCE`, `HOLD`, `REJECT`
        </ResponseField>

        <ResponseField name="aiScore" type="integer">
          Score the AI assigned for this round
        </ResponseField>

        <ResponseField name="aiReasoning" type="string">
          The AI's explanation for its verdict
        </ResponseField>

        <ResponseField name="aiProducedAt" type="string">
          ISO 8601 timestamp when the AI produced the verdict
        </ResponseField>

        <ResponseField name="effectiveVerdict" type="string">
          Derived verdict that resolves the override's verdict when present, otherwise the AI verdict, so clients render the right pill without computing it twice. One of `ADVANCE`, `HOLD`, `REJECT`
        </ResponseField>

        <ResponseField name="override" type="object">
          Recruiter override block; null when the AI verdict has not been overridden

          <Expandable title="AiDecisionOverride Object">
            <ResponseField name="verdict" type="string">
              Overriding verdict. One of `ADVANCE`, `HOLD`, `REJECT`
            </ResponseField>

            <ResponseField name="reason" type="string">
              Reason the recruiter recorded for the override
            </ResponseField>

            <ResponseField name="byUserId" type="string">
              Identifier of the user who applied the override
            </ResponseField>

            <ResponseField name="at" type="string">
              ISO 8601 timestamp when the override was applied
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| `UNAUTHENTICATED` | Missing or invalid API key or bearer token |
| `FORBIDDEN` | The caller is not permitted to read decisions for this tenant |
| `BAD_USER_INPUT` | `jobId` is not a valid UUID or a filter value is not a valid enum member |
| `INTERNAL_SERVER_ERROR` | Unexpected server-side failure while reading decisions |
