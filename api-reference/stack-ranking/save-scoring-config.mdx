## Overview

Overwrite the entire stored scoring configuration for the caller's organization — stage weights, resume rubric weights, competency mix, preset labels, and AI-recommended flags. This mutation backs the Save button on the recruiter Settings Scoring tab and is a full replace: the payload you send becomes the org's one scoring record. Use the sibling `scoringConfig` query to read the saved configuration back; it returns null if the org has never saved one.

<Warning>
This operation requires the `decisions:write` scope and mutates the hiring decision audit trail. It is never available in the default read tier.
</Warning>

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Mutation

```graphql
mutation saveScoringConfig($input: SaveScoringConfigInput!) {
  saveScoringConfig(input: $input) {
    tenantId
    stageWeights {
      id
      label
      percent
      iconKey
    }
    resumeRubricWeights {
      id
      label
      percent
    }
    competencyWeights {
      id
      label
      percent
    }
    hrCompetencyOverrides {
      id
      label
      percent
    }
    stagePresetLabel
    stageSectionAiRecommended
    competencyDescription
    competencyPresetLabel
    competencyIsAiRecommended
    createdAt
    updatedAt
    updatedBy
  }
}
```

## Request Parameters

<ParamField body="stageWeights" type="array" required>
  Weight rows for the hiring stages. Each row is an object with `id` (string, required), `label` (string, required), `percent` (float, required, 0-100; the section is expected to total 100), and an optional `iconKey` icon hint for stage rows: `file`, `phone`, `video`, `users`, or `user`.
</ParamField>

<ParamField body="resumeRubricWeights" type="array" required>
  Weight rows for the resume scoring rubric. Same row shape as `stageWeights`: `id`, `label`, `percent` (0-100, section totals 100), optional `iconKey`.
</ParamField>

<ParamField body="competencyWeights" type="array" required>
  Weight rows for the competency mix. Same row shape as `stageWeights`.
</ParamField>

<ParamField body="hrCompetencyOverrides" type="array">
  Optional sparse HR-specific competency-weight modifier. Each entry overrides the bot-bundled weight for a matching competency on HR-round reports. Omit or pass an empty array to keep the bot's bundled HR weights unchanged.
</ParamField>

<ParamField body="stagePresetLabel" type="string" required>
  Label of the preset the stage weights section currently reflects.
</ParamField>

<ParamField body="stageSectionAiRecommended" type="boolean" required>
  Whether the stage weights section is flagged as AI-recommended.
</ParamField>

<ParamField body="competencyDescription" type="string" required>
  Free-text description shown with the competency mix section.
</ParamField>

<ParamField body="competencyPresetLabel" type="string" required>
  Label of the preset the competency mix currently reflects.
</ParamField>

<ParamField body="competencyIsAiRecommended" type="boolean" required>
  Whether the competency mix is flagged as AI-recommended.
</ParamField>

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid authentication credentials |
| FORBIDDEN | Caller lacks the scoring write permission; saving is Admin only |
| BAD_USER_INPUT | Schema validation of the payload failed (for example, malformed weight rows) |
| INTERNAL_SERVER_ERROR | Unexpected server-side failure while persisting the config |
