## Overview

Retrieve recruiter-facing explanations of why the analyzing AI produced the four report sections — summary, positive signals, risks and flags, and decision rationale — for a single candidate's latest analyzed interview of the requested type. Each call triggers a fresh LLM round-trip; results are intentionally not cached so the caller always sees a current explanation. Use this to explain the scores surfaced by ranking operations such as `jobLeaderboard`, rather than to fetch the scores themselves.

## Endpoint

```
POST /graphql
Content-Type: application/json
```

## GraphQL Query

```graphql
query ScoreJustifications($candidateId: UUID!, $interviewType: InterviewReportType!) {
  scoreJustifications(candidateId: $candidateId, interviewType: $interviewType) {
    summary
    positiveSignals
    risksAndFlags
    decisionRationale
  }
}
```

## Request Parameters

<ParamField body="candidateId" type="string" required>
  UUID of the candidate whose interview report to explain
</ParamField>

<ParamField body="interviewType" type="InterviewReportType" required>
  Which interview modality the justification should explain. Allowed values: `PHONE` (latest analyzed phone-call row), `VOICE` (latest analyzed AI-interview row with mode VOICE), `AVATAR` (latest analyzed AI-interview row with mode AVATAR)
</ParamField>

  <Expandable title="data properties">
    <ResponseField name="scoreJustifications" type="object">
      AI-authored justifications for the four report sections. Any field may be null when the underlying analysis has not produced the corresponding section yet (for example, analysis still running, or nothing material to justify)

        <ResponseField name="summary" type="string">

        <ResponseField name="risksAndFlags" type="string">

        <ResponseField name="decisionRationale" type="string">

## Error Responses

| Error Code | Description |
|------------|-------------|
| UNAUTHENTICATED | Missing or invalid API key or bearer token |
| FORBIDDEN | Caller's role does not permit reading this candidate's interview reports |
| BAD_USER_INPUT | `candidateId` is not a valid UUID or `interviewType` is not a valid enum value |
| NOT_FOUND | The candidate has no analyzed interview of the given type |
| INTERNAL_SERVER_ERROR | Unexpected server-side failure, including LLM generation errors |
