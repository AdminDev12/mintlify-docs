## Who this is for

Developers building event-driven integrations.

## Overview

Webhooks deliver HTTP callbacks when platform events occur. Configure webhook endpoints in your Exterview dashboard or via API.

## Configuration

1. Register your endpoint URL in the Exterview dashboard
2. Store the signing secret securely
3. Implement signature verification on incoming payloads
4. Handle events idempotently using event IDs

## Signature verification

Verify webhook authenticity using the signing secret provided at registration. Reject payloads that fail verification.
