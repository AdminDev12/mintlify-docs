  <Accordion title="December 2025 — Innovations, Upgrades, and Corrections" defaultOpen icon="gift">
    **1. Careers Page & Job Apply**

    A fully functional public careers page has been implemented for each organization, enabling seamless job discovery and applications.

    Key features include:

    - **Public careers page** deployed per organization
    - **Apply-to-job API** integrated for application submissions
    - **Job listing API** powering the careers page
    - Users can now **publish jobs directly** from the job creation step
    - Enhanced careers layout with improved **spacing and responsiveness**

    **2. Job Creation & Job Details**

    The job creation experience has been streamlined with several user-friendly enhancements:

    - **Simple Job Creation flow** with auto-default human interview settings
    - **Job Type field** now available during job creation
    - Fixed **table height and footer alignment** in create job flow
    - **Deadline date picker** now restricts past dates with helpful popup messaging
    - **Redesigned KPIs component** on Job Details page using Darwinbox reference for improved visual clarity

    **3. Onboarding**

    A comprehensive end-to-end onboarding experience has been completed:

    - **Full onboarding flow** from start to finish
    - **Confetti animation** celebrates plan selection
    - **Auto logout & redirect** on session expiry for security
    - Workflow updates supporting new Lambda functions
    - API updates for seamless onboarding data management
    - API endpoints to **create org, create user, attach plan, and save preferences**
    - **Organization utilities endpoint** added for better org management

    **4. Profile Match Analysis**

    Several issues affecting the profile match analysis feature have been resolved:

    - **Category reset on save** issue fixed
    - **Autocorrect interference** with typing resolved
    - **Overall score** now updates instantly for real-time feedback
    - **Input clearing issues** eliminated

    **5. Candidate Profile & GitHub Analytics**

    Candidate profiles have been significantly enhanced with new analytical capabilities:

    - **Candidate profile in Step 3** featuring resume viewer and side-curtain analysis
    - **GitHub analytics** integrated directly inside candidate profile
    - **Developer classification using AI** within GitHub analytics for technical role assessment

    **6. Resume Builder (Azure Migration)**

    The resume builder has been modernized with a complete Azure migration:

    - **Removed DB dependency**, now uses local storage for better performance
    - **Migrated from OpenAI to Azure OpenAI** for improved reliability
    - Updated **next.config.mjs** to include external packages for server components
    - **Refactored resume upload API** with Azure OpenAI initialization and PDF parsing
    - Enhanced **HTML generation** for downloadable resumes with better formatting

    **7. Video / Meeting / Participant Layouts**

    Interview video experience has been refined with multiple layout improvements:

    - Fixed **video tile layout issues** for consistent display
    - Resolved **grid issues** in YouTube tutorial layout
    - Added **dynamic zoom level detection** for adaptive layout changes
    - Improved **video player styles and responsiveness**
    - **MeetingContainer** now supports new dynamic layout switching capabilities

    **8. UI & UX Enhancements**

    Platform-wide visual and usability improvements:

    - **Dark theme global fix** — forced background white, text black for readability
    - Updated **toaster icons** with categorization by success, warning, and failure
    - **Header displays percentage overlay** for credit usage visibility
    - Improved **careers and dashboard UI spacing** for better visual hierarchy
    - Added **25 FAQs to Help Center** for self-service support

    **9. Feedback & File Uploads**

    File management in feedback workflows has been enhanced:

    - **Refactored Feedback dialog** for multiple file attachments
    - Added **per-file removal capability** for granular control
    - Implemented **file size validation** with proper error messages

    **10. Billing & Credits**

    Financial management interface has been redesigned:

    - **Billing UI layout** completely redesigned for clarity
    - **Credit usage percentage overlay** prominently displayed in header

    **11. Notifications & Authentication**

    Communication and security features have been strengthened:

    - **SMS notification system** implemented for timely updates
    - **OTP system** implemented for secure authentication

    **12. Workflow / Infra / APIs**

    Backend infrastructure has been enhanced with multiple improvements:

    - **Additional workflow lambdas** added for automation
    - **API enhancements** for onboarding and job-related flows
    - **Org utilities API** added for managing pending organizations
    - **Auto-logout on session expiry** for improved security

  <Accordion title="November 2025 — New Features, Improvements & Fixes" icon="star">
    **1. Job Dashboard Interview Visibility Enhanced**

    Scheduled and completed interviews were not visible in the job dashboard.

    New **Job Profile KPIs** now provide visibility into interview workflow at a glance.

    **2. Cross-Organization Jobs & Candidates Visibility Implemented**

    Recruiters could previously see only their own jobs and candidates.

    We now provide **full organization-wide visibility**, allowing all recruiters to access all jobs and candidates across the company.

    **3. Candidate Email Join Link Reliability Improved**

    Connectivity issues prevented some candidates from joining interviews via email links.

    A patch has been deployed to ensure all email links are reliable and accessible.

    **4. Additional Bulk Parsing & Interview Sending Stability Updates**

    Additional performance improvements were made to ensure smoother operation for sending AI interview invites and bulk resume parsing.
  </Accordion>
  <Accordion title="October 2025 — What's New & What's Improved" icon="rocket">
    **1. Screening Questions Edit Feature Added**

    Recruiters can now modify screening questions even after job creation using the **Edit Job** option.

    **2. Recommended Section Logic Updated**

    Candidates scoring above 70% were not moving into the Recommended section.

    The process has been improved:

    - An eligibility column (yes/no) has been added
    - Movement now depends on the **human interview verdict**

    **3. Organizer Interview Link Access Enabled**

    Organizers/recruiters were not receiving interview join links.

    This issue has been fixed, organizers now consistently receive links for candidate coordination.

    **4. Candidate Interview Link Access Issue Resolved**

    Some candidates were unable to join interviews through their email links.

    Email join links have been stabilized and now function reliably.
  </Accordion>
  <Accordion title="September 2025 — What's New & What's Improved" icon="sparkles">
    **1. AI Interview Deadline Modification Process Clarified**

    Recruiters requested guidance on updating AI interview deadlines for existing candidates.

    A clear workflow has now been implemented:

    **Job → Actions → Edit Job → Update Deadline**.

    Changes apply to all pending candidates.

    **2. AI Interview Invite Threshold Configuration Added**

    AI invites were being sent inconsistently.

    The system now sends AI interview invites **only to candidates scoring above the benchmark threshold.**

    This ensures improved quality control and candidate filtering.

    **3. AI Interview Status Now Visible in Candidates Section**

    The AI interview status was missing from the Candidates tab.

    This has been addressed, and statuses are now fully visible in **Job Details → Candidates**.

    **4. Bulk Parsing & AI Interview Sending Issues Fixed**

    Users faced issues when sending AI interviews or uploading multiple files.

    Enhancements include:

    - Support for **docx, pdf, and text** files
    - Bulk upload limit increased to **20 files**

    These changes stabilize the interview sending workflow.
  </Accordion>
  <Accordion title="August 2025 — Feature Rollouts, Enhancements & Bug Fixes" icon="wrench">
    **1. AI Interview Verdict Added to Reports**

    A post-interview report is now generated for all AI interviews, clearly showing whether a candidate is

    **"Recommended"** or **"Rejected."**

    **2. AI Voice Not Audible in Recordings**

    If the AI voice is not audible during screen sharing, please ensure that

    **system audio sharing is enabled**. This resolves the issue.

    **3. Human Interview Report Visibility Issue is Fixed**

    Previously, when the **Human Interview** toggle was switched off, interview reports for candidates who had completed their human interview were not visible. This issue has now been **fixed**, and reports remain visible regardless of toggle changes.

    **4. Meaning of "Not Available" Status**

    The status **"Not Available"** in the interview report indicates that the system could not generate a verdict due to the **benchmark settings** configured on the job description page.

    **5. Subtitles Support Added**

    Subtitles are now available during AI interviews for both:

    • **AI Voice**

    • **AI Avatar**

    This enhancement improves accessibility and clarity during the interview.
  </Accordion>
