## Released

<AccordionGroup>

<Accordion title="June 2026 — Microsoft Marketplace GA (June 30)" icon="rocket" defaultOpen>

The launch. The commercial and reliability layer around the Marketplace listing is hardened for general availability.

**Microsoft Marketplace — Live & Transactable**

- Transact EX directly through the Microsoft Marketplace listing
- Meter usage across all four billable dimensions — resume, phone, voice, avatar
- Review usage and capacity-entitlement consumption in-product

**AI Avatar Interviewer — Early Access**

- Run a video-avatar interview as a guided early-access experience
- Capture integrity and recording consent before the interview
- Recording capture and webhook handling hardened (BYO Azure Blob storage, VNet proxy, authenticated callbacks)

**Reliable Billing**

- Usage is metered only on interviews that reached a completed state with an AI decision — incomplete sessions emit no charge
- Billing is idempotent per report, so retries never double-charge

</Accordion>

<Accordion title="May 2026 — Microsoft integrations & early access" icon="layer-group">

Microsoft-native surfaces, the Marketplace billing pipeline, report sharing, and workspace polish ship on the launch runway.

**Microsoft-Native Integrations**

- Sign in with Microsoft Entra ID SSO

**Marketplace Billing Pipeline**

- Azure Marketplace billing integration: subscription lifecycle, post-purchase landing, and subscription linking
- Capacity / metering pipeline and per-dimension entitlement reads
- Trial-expiry and org-usage aggregation timer functions

**Report Sharing**

- Share a candidate report internally, publicly, or as a restricted, email-bound, OTP-verified link with expiry

**AI Avatar Interviewer (early access)**

- Run a video-avatar interview (Tavus-based) as a guided early-access experience

**Platform Polish**

- New status and view tabs on Jobs and Candidates, including an Internal Pool tab
- Refined, debounced search and shared filter controls
- Updated analytics widgets across jobs and candidates
- Consolidated agent reports rendered through one report surface

</Accordion>

<Accordion title="April 2026 — The interview agents" icon="microphone">

Customers can now run fully automated voice interviews, with the consent, scheduling, and candidate-side flows that make them compliant. The decision surface arrives alongside.

**AI Voice Interviewer**

- Schedule a voice interview with a candidate and send the invite via email
- Capture candidate integrity consent and recording consent before the interview
- Review the voice interview report after completion

**Candidate Interview Experience**

- Land on a branded interview lobby
- Run a device check (mic, camera, network) before joining
- See clear progress indicators during the interview
- Land on a post-interview thank-you screen

**Recruiter Dashboard**

- See the overview analytics dashboard on landing
- Review agent analytics: sessions and reports across agents
- See recent activity from across the workspace

**Decision Surface**

- Candidate Leaderboard: candidates ranked across all rounds per job
- Override the AI decision for a single round or overall, with the AI's justification shown
- Consolidated candidate report across resume, phone, and AI-screening (voice / avatar) signals

**Interviewer Persona**

- Sign in with the Interviewer role

</Accordion>

<Accordion title="March 2026 — The first three AI agents" icon="wand-magic-sparkles">

EX goes from a passive system of record to an active hiring engine. Email and in-app notifications and the commercial layer ship alongside.

**AI Role Builder**

- Create a job by uploading a JD file, from a natural-language prompt, or manually
- Configure detailed job settings
- Build the candidate questionnaire (phone agent + AI screening)
- Use AI-suggested interview questions and configure custom scoring categories per job
- Publish jobs to the careers page

**AI Candidate Matcher**

- Upload candidates in bulk via file (async, parallel worker)
- Pull candidates from the internal talent pool
- View stack-ranked candidates per job with AI-generated resume analysis
- Review the match report for any candidate

**AI Phone Screener**

- Trigger an outbound AI phone screen to any candidate
- Review the phone-screen report after a call completes

**Email Notifications**

- Send invite-approval emails to recruiters and admins
- Send AI interview invitations to candidates
- Send trial-welcome emails

**In-App Notifications**

- Open the in-app notification center
- See alerts when an interview completes
- Mark notifications as read

**Billing, Careers & Logs**

- Browse available billing packages
- Manage the public careers page and post jobs to the branded careers page
- Browse the tenant activity / telemetry logs view with date-range and free-text search

</Accordion>

<Accordion title="February 2026 — Core entity management" icon="database">

Jobs, Candidates, and Customers become first-class objects with their own views, actions, and detail panels — plus the configuration surfaces the AI agents read from.

**Jobs Workspace**

- Switch between list, grid, and tab views
- Search across all jobs; apply filters
- Review job KPIs in the analytics panel
- Open a job to see primary info and its candidate leaderboard
- Browse the candidates table within a job; expand any row
- Open the AI agent report for the job

**Candidate Workspace**

- Switch between list and grid views; search and filter the pool
- Open the candidate detail view to override status
- Review overview, experience, and skills tabs
- Read agent reports tied to the candidate and the full activity log
- Upload your own resume as a candidate

**Customer Workspace**

- Create a new customer record; browse in list or grid view
- Open the detail view to see firmographics
- View contacts and jobs linked to each customer
- Edit any customer's profile

**AI Screening Configuration**

- Configure phone-screen settings org-wide and AI interview / voice / avatar defaults
- Build the hiring pipeline stages and define skills used across roles
- Set stage, resume-rubric, and competency weights
- Create reusable pipeline templates

**Data & Audit**

- Browse the granular audit log of every action
- Per-container data-retention TTLs on PII (recordings, transcripts)

</Accordion>

<Accordion title="January 2026 — Foundation" icon="flag">

Self-serve onboarding, authentication, the super-admin control plane, and organization scaffolding come online — making it possible for the first orgs to land on EX safely.

**Self-Serve Onboarding**

- Sign up with social login or via magic link
- Complete organization setup during first run
- Select the AI agent, voice, and avatar that represent the org
- Pick a plan from the plan selector
- Invite the team in the same flow

**Authentication & Access**

- Reset a forgotten password via email
- Log out of the active session (and sign out of all devices)

**Super Admin Console (internal)**

- View organization-wide KPIs at a glance
- See the full list of organizations on the platform
- Open any organization's profile to inspect setup
- Toggle Trial mode and Enterprise mode on an organization

**Organization, Users & Localization**

- Edit personal and org profiles
- Set up company locations across India, US, and EU
- Configure departments
- Define roles for Recruiters and Super Admins (multi-tenant RBAC + permission matrix)
- Add and manage users in the workspace
- View the workspace on mobile-responsive web

**Support & Lifecycle**

- Send the trial-welcome email when an org starts a trial
- See polished error, empty, and 404 / 500 states across the product

</Accordion>
