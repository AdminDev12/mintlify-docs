## Who this is for

Recruiters, compliance reviewers, and admins who need to understand where each evaluation signal originated.

## Overview

The **Agent Transparency Panel** surfaces provenance metadata for every signal in an evaluation. This supports auditability and aligns with Exterview's human-in-the-loop principle.

## Provenance tags

| Tag | Meaning |
|-----|---------|
| **Server** | Signal generated by an Exterview agent on the platform |
| **Client** | Signal provided by the customer, candidate, or integrated system |
| **Synthesized** | Signal combined from multiple server and client sources |

## What the panel shows

For each evaluation signal, the panel displays:

- Which agent produced the signal
- Provenance classification (server / client / synthesized)
- Model and rubric version used
- Timestamp of generation
