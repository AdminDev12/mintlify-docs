## Who this is for

Compliance teams, recruiters, and admins monitoring fairness across evaluation workflows.

## Overview

Exterview provides bias detection and fairness monitoring tools that help customers identify and investigate potential adverse impact in their evaluation pipelines.

## Adverse-Impact Matrix (AIM)

Evaluates fairness across recruitment stages by comparing selection outcomes between demographic groups.

### Controls

- **Weighted**: Apply weighted calculations based on group size
- **Show n**: Display sample sizes for each group
- **Suppress &lt;N**: Hide values with insufficient sample sizes

## Parity & drift timeline

A line chart visualizing fairness trends over time, tracking changes in parity and potential scoring drift.

## Interviews audit table

A review table listing interviews that triggered bias checks, with expandable details for investigation.

| Column | Description |
|--------|-------------|
| Interview ID | Identifier for the interview under review |
| Role / Stage | Job role and recruitment stage |
| Decision + Score | Interview outcome and evaluation score |
| Bias Score | Bias risk level detected |
| Flags | Bias-related alerts triggered |
| Reasoning | Expandable narrative explaining the flag |
| Protected Attribute | Whether demographic attributes were considered |
| Model / Rubric | Model version and rubric used |
| Reviewer & Actions | Reviewer info and available actions |
| Timestamp | When the interview was evaluated or flagged |
