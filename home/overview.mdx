## Welcome to Exterview

Exterview is a **Human + Agent Workforce Evaluation Platform**. It combines specialized AI agents with human-in-the-loop review to help enterprises evaluate candidates at scale without automated adverse hiring decisions.

Use this portal to integrate via API and MCP, complete security diligence, or operate the platform as an admin.

## API at a glance

The Exterview API is a single **additive-only GraphQL endpoint** with REST endpoints for file uploads.

<CodeGroup>

```bash Production
https://api.exterview.ai/graphql
```

```bash Sandbox
https://sandbox-api.exterview.ai/graphql
```

</CodeGroup>
