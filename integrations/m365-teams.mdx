## Who this is for

Microsoft-aligned enterprises and teams using the M365 ecosystem.

## Status

**Available**

## Capabilities

| Feature | Description |
|---------|-------------|
| **Microsoft Entra ID SSO** | Sign in with enterprise Microsoft identity |
| **Teams webhooks** | Receive recruiter alerts in Microsoft Teams |
| **Outlook calendar** | Schedule interviews directly from Outlook |
| **M365 deep links** | Open candidate records via Microsoft 365 links |
| **Microsoft Marketplace** | Transact Exterview through the Microsoft Marketplace |

## Azure alignment

Exterview infrastructure runs on Azure regions. Data residency maps to Azure region deployment see [Platform coverage & residency](/trust-compliance/platform-coverage-residency).
