## Who this is for

Developers integrating Exterview via the Model Context Protocol (MCP).

## Overview

The Exterview MCP server exposes platform capabilities as MCP tools and resources for AI clients (e.g., Cursor, Claude Desktop).

## Authentication

MCP connections use the same credential model as the API:

- Organization API key (`x-api-key`)
- Bearer token (`Authorization: Bearer YOUR_TOKEN`)

See [Authentication](/api-reference/auth) for credential setup.

## Example connection

```json
{
  "mcpServers": {
    "exterview": {
      "url": "https://mcp.exterview.ai/sse",
      "headers": {
        "x-api-key": "YOUR_API_KEY",
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}
```
