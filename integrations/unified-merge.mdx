## Who this is for

Integration engineers needing connectivity to ATS/HRIS platforms not directly supported by Exterview.

## Status

**Beta**

## Overview

Unified.to and Merge.dev provide normalized APIs across hundreds of HR systems. Use these platforms as a connectivity layer when direct ATS integration is not available.

## Supported use cases

- Candidate data sync from ATS to Exterview
- Evaluation status push back to ATS
- Normalized field mapping across HRIS vendors
