| Data type | Stored in tenant region | Cross-border transfer |

| Evaluation results | Yes | Same as candidate PII |
| Audit logs | Yes | Same as candidate PII |
| Model artifacts (compounding) | Yes — per-tenant | Never cross-tenant; region-scoped |
