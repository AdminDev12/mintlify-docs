## Security controls

### Encryption

- **In transit**: TLS 1.2+ for all API and UI traffic
- **At rest**: AES-256 encryption for stored data in Azure

### Access control

- Role-based access control (RBAC) per tenant
- API key and Bearer token authentication for programmatic access
- SSO via SAML/OIDC for enterprise identity (see [SSO / SCIM](/integrations/sso-scim))

### Audit logging

- Granular audit log of every platform action
- Filterable by user, action, and date range
- Retention policies configurable per region

### Infrastructure

- Azure-native deployment with regional data residency
- Per-tenant data partitioning: see [Multi-tenancy & data isolation](/concepts/multi-tenancy-data-isolation)

## Requesting security documentation

SOC 2 and ISO reports are available via gated request not as public downloads. See [Certifications](/trust-compliance/certifications).
